# mode-duration-compression

测时长压缩模式：重选而非等比裁剪 + 压缩后读稿闭环。

## Input

```text
用 loop-script-writer 的时长压缩,把这条 3 分钟 B站口播(约 780 字,含钩子、
4 个技巧点各带案例、结尾 CTA)压成 60 秒抖音版(标准语速)。
[附完整 3 分钟稿:钩子为反常识型;技巧 1 最强(带前后数据对比);技巧 2-3 中等;技巧 4 最弱]
```

## Expected behavior

- 识别方括号内为摘要／占位符，不是完整原稿。
- 索取完整可读取原文，停止压缩；不补造四个技巧或任何数据。
- 可以说明下一步流程，但不输出假装来自原稿的口播。

## Pass criteria

- 明确缺全文；没有压缩稿。
- 不把摘要扩成原文，不声称已处理附件。
