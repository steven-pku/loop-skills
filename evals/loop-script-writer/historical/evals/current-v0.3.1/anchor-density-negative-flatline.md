# anchor-density-negative-flatline

Anchor pair C（负例）。配对：`anchor-density-positive-curve`。测信息密度曲线。

## Input

```text
QA Only 诊断这条 3 分钟(标准语速)B站口播稿的中段(钩子已过关,只看密度):
[稿件中段约 400 字:从第 30 秒到第 90 秒全部在讲作者自己怎么开始做视频的经历——
辞职心路、买第一台相机、第一条视频发布时的紧张——没有一个可带走的方法或结论,
承诺的「三个涨粉技巧」到 90 秒还没出现第一个]
```

## Expected behavior

- 信息密度曲线低分:60 秒无价值点（超过「每 10 秒一个价值点或转折」，3min 档也远超放宽标准）
- 指认「承诺未兑现风险」：技巧承诺 90 秒未兑现——若全稿都如此则 fatal,中段诊断先给预警
- 个人经历段的处理建议：压缩为一句背书（F1）或拆为技巧的案例插曲，不是删光

## Pass criteria

- 密度判定给出量化依据（N 秒无价值点）
- 不把「有个人故事」本身当问题（问题是密度，不是内容类型）
