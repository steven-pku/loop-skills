# mode-duration-compression

测时长压缩模式：重选而非等比裁剪 + 压缩后读稿闭环。

## Input

```text
用 loop-script-writer 的时长压缩,把这条 3 分钟 B站口播(约 780 字,含钩子、
4 个技巧点各带案例、结尾 CTA)压成 60 秒抖音版(标准语速)。
[附完整 3 分钟稿:钩子为反常识型;技巧 1 最强(带前后数据对比);技巧 2-3 中等;技巧 4 最弱]
```

## Expected behavior

- 重选逻辑:保钩子 + 兑现其承诺的最强价值点(技巧 1),舍弃 2-4——**不是**每个技巧各删 75%
- 压缩后跑读稿 pass:目标 260 字 ±15%,报告偏差;超出则再调,不是删完即交
- 平台切换被处理(B站 → 抖音:节奏/评论钩差异,platform-notes 各自「脚本含义」)
- 轻量 QA(fatal 扫描)执行;承诺兑现链在压缩版中重新检查(原承诺若指向 4 个技巧,压缩版承诺须改写为 1 个,否则「承诺未兑现」)

## Pass criteria

- 产出为重选后的完整 60s 双列稿,字数在容差内
- 原稿「4 个技巧」类承诺在压缩版被改写(不留断头承诺)
