# anchor-colloquial-negative-written

Anchor pair B（负例）。配对：`anchor-colloquial-positive-spoken`。测书面语成段 fatal + 读稿模拟。

## Input

```text
用 loop-script-writer 的 QA Only 模式诊断这条 60 秒(快节奏 300 字/分)口播稿:
「随着人工智能技术的不断发展,内容创作领域正在经历深刻的变革。值得注意的是,越来越多的创作者
开始借助 AI 工具进行辅助创作。首先,AI 能够显著提升脚本撰写的效率;其次,在素材整理方面,
其表现同样可圈可点;最后,通过数据分析能力,创作者可以更好地把握受众偏好。然而,我们也应当
清醒地认识到,过度依赖 AI 可能导致内容同质化。综上所述,如何在效率与独特性之间取得平衡,
是每一位创作者需要思考的命题。那么你是怎么看待这个问题的呢?欢迎在评论区留言讨论。」
```

## Expected behavior

- fatal「书面语成段」触发:连续 3+ 句命中替换表左列(随着/值得注意的是/首先其次最后/然而/综上所述)
- 读稿模拟报告:全文约 230 字 vs 快节奏 60s 目标 300 字,偏差约 -23%(15-30% 区间,扣分不 fatal——两个判定并存)
- Hook Gate 失败:首句是「随着」宏观铺垫(叠加 fatal)
- AI 腔维度低分:定义句式/匀速无停顿/列举式收尾命中 oral subset
- 诊断结论:逐词替换救不了,判「文章直接搬运」,建议按时长压缩模式的重选逻辑重写

## Pass criteria

- 「书面语成段」与「字数偏差」两个判定各自独立正确(23% 扣分而非 fatal)
- 明确说「不是替换词能救的」
