**结论：这条 F2 属于“本人称已核、本轮不可复核”，不是“从未核实”，不因档案缺席触发证据 fatal。** 整份 brief 仍需 **Revise**，明确缺口是未提供有效止损位；状态保持 **Proposed／待决定**。

Type 1 判定成立：离职后原岗位不保留，不能把“再回原岗位”当作可行回退。

| brief 内容 | 事实类别与核验状态 |
|---|---|
| “更重视成长而不是头衔” | **F0 偏好**，无需外部证据，也不因此扣事实分 |
| “工作内容更匹配” | 作为本人对适配度的评价，可记 **F0**；若进一步断言具体职责或未来成长结果，需分别提供事实依据 |
| 家庭照护是硬约束；原岗位不保留；决策权归属、时限、等待一周不失去 offer、当前无额外压力 | **F1 当事人给定事实／约束**，注明本人提供；照护的具体边界仍待补 |
| “当前收入稳定” | **F1 本人现状陈述**；不能自动延伸为未来半年收入必然稳定 |
| “上周已经逐条比对” | **F1 本人对核验行为的陈述** |
| “B 年度报告和客户续约清单的留存率口径一致” | **F2 可核事实**；类别不变，另记核验者、方法与本轮复查限制 |
| F3 | 当前没有明确提出法律、税务等专业载重断言；不能仅因岗位变动重大就把全部依据升级为 F3 |

**证据分档：**就这条 F2 而言，已交代核验人、时间、材料和逐条比对方法，可支持 rubric 的 **18–20 分高档特征**，但必须保留“本人自述、本轮未独立复核”的限定。不能仅因缺附件降入“待核有计划”的 12–17 档，更不能降成“未核无计划”的 6–11 档。整份 brief 的证据清单尚不完整，因此不据这一条给全案满分。

相关 fatal 应分别判断：

| 规则 | 本案判断 |
|---|---|
| 只有一个真选项 | **未命中**。A 的适配、B 的连续性、C 的稳定与延后观察，各有合理理由；没有依据认定 B、C 是陪跑 |
| 载重 F2 未核且无有效计划／F3 无源 | **这条 F2 不命中**。缺档案是审查限制；当前也没有明确的无源 F3 |
| 无有效止损位 | **所给 brief 命中**。没有完整的“可观察信号＋监测负责人＋可行响应动作”；“半年再看”只是时间点 |
| Type 1 到备忘录阶段仍未做 premortem | **当前初审不触发**。材料未提供 premortem，不能推断本人从未做过；正式出备忘录前需完成 |
| 结论先行且拒不承认 | **无依据判定**。成长偏好不等于已经选定 A |

建议把关键证据直接修订为：

> **F2：**B 年度报告与客户续约清单的留存率口径一致。  
> **核验记录：**据本人陈述，上周由本人逐条比对上述两份材料。  
> **本轮审查状态：**档案未随会话提供，模型未独立复核；材料具体版本、覆盖范围及比对细节未知。此限制不等于从未核实，也不证明结论错误。

仍须区分：**口径一致本身不能证明留存率高、趋势稳定或新岗位未来三年的成长性。** 如果这些也是选择 A 的关键理由，应另列主张与依据，不能让现有 F2 承担未证明的结论。材料提供者、清单选择者未知，也不能据此补写“招聘方筛选了样本”。

最小修正与补件为：

- **证据可复查性：**如需进一步审查，提供当时使用的报告版本／页码、清单范围与时点，以及已有的逐项比对记录或计算说明。这里是所需材料清单，不代表这些记录已经存在。
- **家庭照护门槛与止损：**补具体照护时段、地点／出差限制、替补安排。可提议由本人监测；承诺前若职责安排无法满足照护硬约束，则不推进 A，转评可满足约束的留任选项。入职后的可行响应另需明确，不能假设原岗位可恢复。
- **完整决策准备：**补各选项的预期结果与本人主观概率、B 争取职责的可行依据，并分别做 premortem。概率保持〔待补〕，不代填。

**当前建议：利用不会损失 offer 的一周补齐这些缺口，再比较 A／B／C。** 这是一项 Proposed 的准备建议，尚不足以判定接受新岗位。
