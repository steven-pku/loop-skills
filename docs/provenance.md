# 来源与许可

九款选用公开固定标签的源码树为唯一权威输入；旧 Release 的实际资产已下载并核对运行字节。每款记录标签对象类型、对象 OID、解析 commit、获取时间、源归档摘要、旧资产摘要和逐文件映射。

导入白名单：SKILL.md、运行资源、示例、原许可及已有来源声明。Article 的原评分表引用 evals/cases，因此这些校准案例随单款保留。完整纯评测档案在根 evals 下冻结保存；随包原评审与变更记录所链接的原文依赖另随包保留，避免断链。Git 可携带的执行位保留；普通文件统一为 0644，执行文件为 0755。

每款保留原 LICENSE。Article 保留已有 THIRD_PARTY_NOTICES.md 中的原 MIT 声明；Script 保留其原来源说明。本次没有把第三方规则重新授权，也没有导入私有开发历史、机器入口、重复副本或凭证。

自动扫描可发现部分绝对用户路径及常见凭证形态，不能证明不存在所有敏感内容。公开内容还按固定源白名单复核；测试日志只发布脱敏结果，不发布个人环境索引。

维护工具使用 [PyYAML 6.0.3](https://pypi.org/project/PyYAML/6.0.3/) 解析 frontmatter，依赖不复制进 Skill 包。
