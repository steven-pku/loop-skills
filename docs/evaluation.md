# 评测和证据

## 三种记录

- `evals/<product>/historical/`：固定旧源原文快照，原 HOLD、失败、PARTIAL、NOT_RUN 和环境限制原样保留。
- `provenance/<product>.json`：原来源、标签对象、commit、资产摘要及文件映射。运行字节不变，只继承旧内容身份。
- `evals/<product>/migration/` 与 `evals/routing/`：本次新安装、读取与边界测试，另记输入、宿主、模型、调用结果和审查状态。

历史字节保持不表示新宿主行为已通过；新冒烟也不代替原产品全量评测。本次没有重新计分历史案例。运行文件未改，受迁移影响的资源解析与首次使用由新测试覆盖，额外语义改稿案例 N=0。

## 首批预算

两条项目级路线：Codex CLI、Claude Code。每条九款单装＋九条单意图、两条边界重叠、一条无关请求，共四十二个模型场景；每例最多一次、每例一百八十秒、无自动重试。另有十八条升级恢复序列和四个冲突夹具。首次失败保留；修复后新增记录，不能覆盖失败。

加载判定要求可观察的 SKILL.md 和相应资源读取；只在答案中声称“使用了”不够。先记录执行，再审查选择边界、事实保真、未知保留与输出契约。环境额度或认证失败记 BLOCKED／NOT_RUN，不换模型制造通过。

GPT 6 Pro 已参与架构设计审查；该审查不是本候选安装通过证明。新测试的语义判卷与完成范围另记，不与旧成绩混计。
