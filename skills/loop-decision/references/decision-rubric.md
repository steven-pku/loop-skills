# Decision Rubric — scoring manual

Score the brief /100. For every deduction cite the exact line. The score is directional (Pass / Borderline / Revise), not a calibrated instrument — do not read small gaps as verdicts.

## Dimensions

### 选项充分性 /20

- 18-20：>= 3 个真选项，每个都有「理性人理由」；「不做」被认真评估过（有预期结果和概率，不是一行敷衍）。
- 12-17：选项数够但有一个偏弱；或「不做」只被口头提及。
- 6-11：两个真选项 + 陪跑项；选项间差异是执行细节而非方向。
- 0-5：单选项包装成多选项（fatal 联动）。

### 证据强度 /20

- 18-20：载重事实标签齐全，关键 F2 已核并有核实方式，无裸 F3；真实偏好可保留 F0，不因它是偏好而扣事实分。
- 12-17：标签齐全，但关键 F2 仍待核；每条均有有效的承诺前核实计划与可行回退方案，按待核项的范围及重要性在本档评分。不触发此项 fatal，但不得给已核档。
- 6-11：标签不全、关键主张依赖未经交叉核对的单一来源，或载重 F2 未核且无有效计划；最后一种同时触发 fatal。
- 0-5：主要载重证据普遍是无核实依据的传闻（fatal 联动）。

有效计划定义见 `evidence-grading.md`。分数与 fatal 分别判断；有计划不清除其他 fatal。用户称已核但本轮缺档案不等于从未核实：记录其核实方式、范围和当前可复查限制，不单凭缺附件扣成「未核无计划」，也不补造核验。

### 对立面强度 /20

**阶段适用性**：初评尚未执行红队、且没有足以评分的既有红队记录时，本维写「待评」，整张卡不计算 /100 合计。记录不足不等于稻草人，不以 0 分占位。完成红队后按下面的实际表现复评。若现有材料已经展示稻草人，或已经用未经检验的异议宣布零发现，仍按对应低档评分；不得退回「待评」来回避已观察到的问题。

- 18-20：从 steelman 出发，证据／框架／激励／时机四条攻击线均有认真检验及可核依据；存活异议带否决条件入备忘录。允许零条存活，但须逐线记录被证据排除的理由与残留不确定性，不因数量为零扣分。
- 12-17：有实质检验但覆盖不全，或部分否决条件／排除依据不充分。
- 6-11：红队走过场——异议被口头解释掉，未核验就宣称无发现；不能仅因 brief 未改动判此档。
- 0-5：稻草人反方（fatal 不触发，但本维度记 0 并点破）。

### 失败预案与止损位 /15

- 13-15：有效止损位完整，premortem 产出已转成触发器，监测与响应安排清楚。
- 8-12：已有可观察信号、监测负责人和可行动作，足以执行，但检查频率、备用负责人等细节仍可补强；不因此触发 fatal。
- 0-7：没有有效止损位，或只有装饰性表述（如「不顺就再看」，没有可观察信号、负责人或可行动作），触发 fatal。

**有效止损位**＝可观察触发信号＋监测负责人＋可行响应动作。三个必要项缺任一项均不能依靠该止损位消除 fatal；不可逆损失已发生后才说「回滚」且未说明可行替代动作，也不算有效。

### 利益相关方覆盖 /15

- 13-15：受影响方列全；建议/拍板/执行三权明确（一个拍板人，不是委员会和稀泥）。
- 8-12：列了人但决策权归属含糊。
- 0-7：只见「我」，看不见谁被影响、谁能否决。

### 时机判断 /10

- 9-10：「为什么是现在」有具体答案；等待的成本和新信息的价值被显式比较。
- 5-8：有时限但没论证。
- 0-4：时限缺失，或「现在就要决定」经不起一句追问。

## Fatal issues（任一命中 -> Revise，与分数无关）

1. 只有一个真选项（稻草人 slate）
2. 关键证据 F3 无源，或载重 F2 未核实且无有效的承诺前核实计划（要求见 `evidence-grading.md`；有计划按中档扣分，不触发这一 fatal）
3. 无有效止损位，包括缺必要项或纯装饰性表述（定义见上）
4. Type 1 决策**到出备忘录阶段**仍未跑 premortem（premortem 前的初评 scorecard 不触发此条）
5. 结论先行且用户不认（标注后继续，但记 fatal）

## Verdict bands

- **Pass**：无 fatal 且各维清晰扎实（粗略 ~85+）
- **Borderline**：无 fatal，1-2 个维度明显偏弱 -> 只修最弱维，复评
- **Revise**：任一 fatal，或整体明显薄弱

每张 scorecard 标注累计 loop 计数与阶段：初始预算为 2，`QA loop N/2 · 初评` / `QA loop N/2 · 复评` 共用同一 N。2/2 后停止并交还用户；不变稿复诊不递增也不归零。只有用户随后明确追加有限轮数才提高总预算（例如再 1 轮记为 3/3），保留旧计数与授权记录；模糊续作请求先问轮数，不自动续跑。详见 SKILL.md。
