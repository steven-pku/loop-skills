# Article Brief Template

Use this template before outlining or drafting.

```markdown
## Article Brief

- Topic:
- Platform: 公众号 / 小红书 / X / newsletter / other
- Reader:
- Reader's current state:
- Reader's current misunderstanding:
- Desired result after reading:
- Core stance:
- Article type: opinion / practical method / research note / rewrite
- Platform target:
- Fact risk: low / medium / high
- Supporting materials:
- Required sections:
- Exclusions:
- Tone:
- Output mode:
- Success criteria:
- Assumptions:
- Missing materials:
```

## Example

```markdown
## Article Brief

- Topic: AI 写作为什么越来越像正确废话
- Platform: 公众号
- Reader: 用 AI 辅助写作、但觉得文章越来越空的中文写作者
- Reader's current state: 会写 prompt，也会让 AI 改稿，但改完仍然像套话
- Reader's current misunderstanding: 以为问题是提示词不够长，实际问题是没有观点和改稿规则
- Desired result after reading: 知道先定核心立场，再用 QA Loop 改写文章
- Core stance: AI 写作最容易失效的地方不是生成正文，而是没有把“观点是否成立”放进检查回路
- Article type: opinion
- Platform target: 公众号深度长文，保留判断感，不写成教程
- Fact risk: medium，涉及平台和行业趋势的句子需标记或核实
- Supporting materials: 用户提供的旧稿、一次真实改稿经验、可补充待核案例
- Required sections: hook, target, core stance, case, objection, ending judgment
- Exclusions: 空泛概念、AI 腔、连续排比、百科解释、SEO 套路
- Tone: 经验分享，直接，有判断
- Output mode: Full Loop
- Success criteria: QA >= 85, no fatal issues, stance sharpness >= 18/30
- Assumptions: 可使用模拟案例，但必须标注
- Missing materials: 用户真实失败稿，如有可增强可信度
```
