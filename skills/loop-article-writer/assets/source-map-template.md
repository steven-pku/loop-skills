# Source Map Template

Use this template after research and before outline. Research collects and classifies raw material; Source Map assigns that material to article function and marks fact risk.

```markdown
## Source Map

| Article Function | Material To Use | Claim / Evidence | Fact Risk | Platform Function | Status |
|---|---|---|---|---|---|
| Hook |  |  | low / medium / high | create recognition | ready / missing |
| Core stance / promise |  |  | low / medium / high | tell reader why this matters | ready / missing |
| Problem |  |  | low / medium / high | show why the old way fails | ready / missing |
| Evidence / case |  |  | low / medium / high | make it believable | ready / missing |
| Framework / template |  |  | low / medium / high | make it usable | ready / missing |
| Objection / mistake |  |  | low / medium / high | prevent shallow agreement | ready / missing |
| Ending judgment |  |  | low / medium / high | leave stance or action | ready / missing |
```

## Rules

- Every important claim should be backed by material, experience, or a clearly labeled assumption.
- `Platform Function` should use a functional label such as `create recognition`, `show why old way fails`, `make believable`, `make usable`, `prevent shallow agreement`, or `leave stance`.
- If a row is empty, mark it as missing.
- Do not invent real cases.
- If using a simulated case, label it as `模拟案例`.
- If using unverifiable hard facts in the article body, label them as `〔待核验〕`.
- If using platform-rule claims, label them `〔待核·上线前实测〕` unless verified.
