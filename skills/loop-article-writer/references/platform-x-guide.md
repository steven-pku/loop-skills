# Platform X Guide

Use this reference only when the target platform is X longform or X thread. It is no longer the default platform guide.

## X Longform Principles

X readers are usually scrolling. The article must earn attention quickly.

## Opening

The first 2-3 lines should create tension.

Good opening types:

1. Wrong common behavior

```text
大多数人让 AI 写文章，第一步就错了。
```

2. Counterintuitive claim

```text
文章空，不一定是 AI 不行，更多时候是你没有设计修改回路。
```

3. Personal observation

```text
我发现一个很稳定的现象：越是直接让 AI 写完整文章，越容易得到一篇“什么都对，但没人想看”的稿子。
```

4. Problem diagnosis

```text
如果你的 AI 文章读起来很完整但很空，问题通常不在 prompt，而在流程。
```

Avoid:

```text
今天我们来聊聊……
本文将从三个方面展开……
Loop Engineering 是一种……
```

## Body

Rules:

- Keep paragraphs short.
- One paragraph should usually carry one idea.
- Use numbered steps when teaching a process.
- Avoid heavy tables in final X posts.
- Use examples soon after explaining a concept.
- Do not stack abstract terms.

## Thread Conversion

When converting to a thread:

- Do not simply split paragraphs.
- Each post should create forward motion.
- Every 2-3 posts should add a new concrete idea, example, or rule.
- The first post should contain the hook and promise.
- The final post should give judgment, action, or self-check.

Suggested thread structure:

```text
1. Hook + promise
2. Common wrong way
3. Why the wrong way fails
4. Core idea in one sentence
5. Step 1
6. Step 2
7. Step 3
8. Worked example
9. Common mistakes
10. Final self-check
```

## Thread QA

Thread QA is a five-item structure check, not a rubric score. Report pass/fail per item and quote the failing post:

1. Post 1 contains a hook and a promise the reader could disagree with or act on.
2. Every post moves the thread forward; no post merely restates a previous one.
3. Each 2-3 posts add a new concrete idea, example, or rule — no abstract-only stretches.
4. The final post gives a judgment, action, or self-check, not a summary or thanks.
5. For Chinese threads, carrier sentences pass the 高频高害 tier of `references/chinese-ai-tone-patterns.md`.

Do not apply the full opinion/method rubric to a thread. If the user wants a full QA score, run it on the longform source article instead.

## Ending

Good endings:

```text
判断一个写作 Loop 有没有成立，不看你写了多少步骤，只看每一轮修改是不是来自上一篇的真实问题。
```

```text
下次写文章前，先别让 AI 写正文。先让它回答三个问题：写给谁、看完做什么、用什么案例证明。
```

Avoid:

```text
希望对你有帮助。
欢迎点赞收藏。
以上就是我的分享。
```
