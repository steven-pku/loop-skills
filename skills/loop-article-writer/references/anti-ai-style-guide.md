# Anti-AI Style Guide

Use this reference when the draft sounds generic, overly polished, over-explained, or obviously AI-written.

This guide is the entry point. For Chinese syntax, structure, and punctuation patterns, also read `references/chinese-ai-tone-patterns.md`.

## Main Rule

Do not make the article sound "more advanced." Make it more specific.

AI-like writing usually fails because it uses abstract language without concrete observation.

## Common AI-Sounding Patterns

### Empty Opening

Bad:

```text
在当今 AI 快速发展的时代，Loop Engineering 正在成为越来越重要的方法。
```

Better:

```text
很多人用 AI 写文章的问题，不是提示词不够长，而是没有让 AI 反复检查自己。
```

### Fake Depth

Bad:

```text
这背后体现的是一种系统化、结构化、闭环化的思维方式。
```

Better:

```text
真正的变化是：你不再一轮轮手动追问 AI，而是提前写好“检查规则”和“下一轮怎么改”。
```

### Excessive Parallelism

Bad:

```text
它不仅提升效率，而且优化流程，更重要的是重塑认知。
```

Better:

```text
它最直接的价值只有一个：把你每次手动催 AI 改稿的动作，提前写进流程里。
```

### Polite Ending

Bad:

```text
希望这篇文章能对你有所帮助。
```

Better:

```text
判断一个写作 Loop 有没有成立，只看一件事：下一轮修改规则是不是来自上一篇文章的真实问题。
```

## Words And Phrases To Challenge

These words are not banned forever, but if they appear, check whether they hide a more concrete point:

- 在当今时代
- 随着科技的发展
- 赋能
- 深度解析
- 不难发现
- 值得注意的是
- 综上所述
- 总而言之
- 希望本文能够
- 打造闭环
- 形成体系
- 提升效率
- 重塑认知
- 底层逻辑

## Rewrite Rules

When a paragraph feels AI-like, apply these rules:

1. Replace abstract nouns with a concrete scenario.
2. Replace "importance" claims with "what problem it solves."
3. Replace general advice with one action the reader can copy.
4. Replace a definition with a contrast.
5. Replace a polite ending with a judgment.
6. Delete any sentence that does not change the reader's understanding.
7. For Chinese drafts, check sentence skeletons and punctuation rhythm in `references/chinese-ai-tone-patterns.md`.

## Paragraph Test

For each paragraph, ask:

1. Does this paragraph say something specific?
2. Does it move the argument forward?
3. Could a human with experience have said this?
4. Is there a concrete noun, action, example, or judgment?

If the answer is no, rewrite or delete it.
