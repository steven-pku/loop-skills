# Script Rubric — scoring manual

Score /100. For every deduction cite the exact line （行号 from the 双列 draft）. The score is directional (Pass / Borderline / Revise), not a calibrated instrument.

先按可见材料选择对应锚点，再在该档内给分。跨档扣分只使用明文规则，不自创罚则；输入只有片段或摘要时，只评价可见部分，不补造全文证据。

## Dimensions

### Hook 强度 /25

- 22-25：前 3 句命中七类之一且对目标观众成立；承诺与兑现点齐备。
- 15-21：有钩子但强度存疑（缺口太小/冲突偏假）；或承诺偏泛。
- 8-14：钩子要素在但埋在背景铺垫后面（第 4 句才出现）。
- 0-7：前 3 句无钩子（fatal 联动）。

### 口语化与节奏 /20

先依据实际用词、呼吸单元与停顿给出语言基础分。绝对时长偏差 >15% 且 ≤30% 时，最终分＝min（语言基础分，17）：只设一次中档上限，基础分已 ≤17 就不再降档或叠加扣分。偏差 ≤15% 不调整；偏差 >30% 另记 duration fatal 并将总判定设为 Revise，语言分仍按真实表达证据判断。报告基础分、时长调整及最终分，不能因时长 fatal 凭空说自然口语变成频繁书面语。

- 18-20：全稿呼吸单元干净；长短句有交替；替换表左列词汇零出现；停顿设计到位。
- 12-17：个别行超呼吸单元或残留书面语（≤3 处）。自然口语原为高档、仅因上述时长上限落入本档时，明确写出原因，不虚构语言问题。
- 6-11：书面语频繁但未成段；节奏平（无停顿设计）。
- 0-5：书面语成段（fatal 联动）或全稿匀速如 TTS。

### 信息密度曲线 /20

- 18-20：每 ~10 秒一个价值点或转折（10min 档放宽至 20-30 秒）；无纯铺垫段。
- 12-17：曲线基本成立，但有多处短支线稀释主线，或中段有一处 >15 秒的平台期。分开记录各段位置和时长，不把不连续支线相加当作连续平台期。
- 6-11：头重脚轻（钩子后密度骤降）或价值点堆在结尾。
- 0-5：通篇铺垫，价值点 ≤2 个。

### 结构完整 /15

- 13-15：承诺-兑现-CTA 链条闭合；CTA 是一个具体动作。
- 8-12：链条在但兑现弱（承诺大兑现小）；或 CTA 泛（「关注我」无理由）。
- 0-7：承诺未兑现或无 CTA（均 fatal 联动）。

### 中文 AI 腔 /10

- 9-10：oral subset 零命中。
- 5-8：中频模式 1-2 处（桥接词/副词堆叠）。
- 0-4：高害模式出现（排比三连/递进套话/列举式结尾/定义句起手）。

### 事实纪律 /10

- 9-10：整稿事实已逐项核对；F2 清零；观点、假设、用户提供事实有明确归属；无无据因果、唯一办法或结果保证。
- 5-8：能明确列出未解决的载重 F2；即使已提示用户仍未核实，只能交诊断草稿，不能标可念稿。
- 0-4：载重数字无标签；或改编场景继承了原文无源断言（unsourced F3 直接 fatal）。

## Fatal issues（任一命中 -> Revise）

1. 开头 3 句无钩子
2. 书面语成段（连续 3 句以上）
3. 已作出的承诺未兑现；通篇未作承诺且无钩子时，仅按第 1 项记 fatal，不重复计
4. 无 CTA
5. unsourced F3
6. 字数偏离时长档超过 30%

## Verdict bands

- **Pass**：无 fatal、无未解决的载重事实且各维清晰扎实（粗略 ~85+）；分数高不豁免 Ship Check
- **Borderline**：无 fatal，1-2 维明显偏弱 -> 只修最弱维，复评
- **Revise**：任一 fatal 或整体薄弱

`QA loop: N/2` 写进每张 scorecard；2/2 后 Graceful Halt。
