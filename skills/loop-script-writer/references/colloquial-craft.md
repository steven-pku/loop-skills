# Colloquial Craft — 口语化工艺

The test for every line: 用嘴说一遍。说不顺 = 改；像念课文 = 改；朋友听了会问「你怎么说话像公众号」 = 重写。

## 书面语 → 口语替换表（高频犯案区）

| 书面语（纸面活、嘴上死） | 口语替换 |
|---|---|
| 综上所述 / 总而言之 | 「所以说白了」「一句话总结」 |
| 值得注意的是 | 「注意啊」「这里有个坑」 |
| 首先…其次…最后 | 「第一件事」「还有一个」「最后这个最重要」 |
| 众所周知 | 直接说事实，或「你肯定也发现了」 |
| 换言之 / 也就是说 | 「说人话就是」 |
| 与此同时 | 「同一时间」「另一边」 |
| 然而 / 但是（句首连用） | 「结果呢」「可问题是」 |
| 进行 + 名词（进行分析/进行优化） | 直接用动词（分析它/把它调快） |
| 基于/针对/围绕 + 名词化短语 | 拆成「谁-做-什么」 |
| 「……的原因在于」 | 「为什么？因为」 |

## 呼吸单元

- **一行口播 = 一口气**。默读时在换气处切行；一行超过 ~20 字基本要拆。
- 长从句是口播天敌：「在我们分析了过去三个月的数据之后发现」→「我翻了三个月的数据。发现一件事。」
- 连续 4+ 个 <5 字短句 = 机关枪节奏，中间放一个长句或停顿喘气。
- 口语允许（书面不允许）的都可以用：重复（「很慢，真的很慢」）、口头禅、半截句（「结果呢——翻车」）、自问自答。

## 双列输出格式

```markdown
| # | 口播 | 画面提示 |
|---|---|---|
| 1 | 这段口播，先只讲一个重点 | 字卡：一个重点 |
| 2 | 把最想说的话，先放到开头 | 稿纸：圈出开头 |
| 3 | 再念一遍，看看哪里需要换气 | （停半拍）手指划出气口 |
```

- 口播列：只写要念的字，一行一呼吸单元。
- 画面列：给拍摄者的提示（字卡/切镜/特写/B-roll），不是分镜表——一句话能开拍即可。
- 停顿写在画面列（「（停半拍）」），read-aloud pass 计时用。

## 「书面语成段」fatal 判定

连续 3 句以上出现替换表左列词汇、名词化堆叠或长从句 = 书面语成段 = fatal。单句书面语是扣分项，成段是结构病——通常意味着这段是从文章直接搬来的，需要按「时长压缩」模式的重选逻辑重写，不是逐词替换能救的。
