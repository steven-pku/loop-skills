# Pacing and Length — 语速锚与时长换算

These figures are **planning assumptions**, not official standards and not measurements of the current speaker. No state standard or peer-reviewed primary source establishing universal Chinese creator-video rates was verified as of 2026-09-20. Prefer the user's measured pace; otherwise declare the chosen profile and show sensitivity when the verdict could flip.

## 语速锚（字/分钟）

| 档位 | 字/分 | 依据与层级 |
|---|---|---|
| 慢速 / 舒适聆听 | 240 | 工作假设；适合留白较多的表达 |
| **标准口播（默认）** | 260 | 中性工作假设；不代表用户实测语速 |
| 快节奏 | 300 | 工作假设；适合知识快讲的敏感性对照 |
| 极限 | 350 | 压力测试档；必须由用户明确选择，不自动假设 |

## Read-Aloud Pass 操作

1. **数字数**：只数口播列。**计数口径**（fatal 判据依赖，必须统一）：中文字符计 1；阿拉伯数字与英文缩写按读音折字（「30」=「三十」计 2，「IP」计 2，「App」计 2）；标点与停顿标记不计。目标 = 时长档 × 语速档；报告「目标 X 字 / 实际 Y 字 / 偏差 ±Z%」。
2. **偏差规则**：绝对偏差 ≤15% 不作时长调整；>15% 且 ≤30% 时，口语化与节奏最终分＝min（语言基础分，17），只设一次上限、不叠加降档；>30% fatal——时长失控是口播脚本三大病之一，不降级处理。**压线判定**（偏差落在 fatal 线 ±5pp 内，或换一个合理语速档结论会翻转）：报告多档敏感性，按用户声明档判定；用户未声明档且结论翻转 → 用一个提问确认语速档再判。
3. **标呼吸点**：一行口播 = 一个呼吸单元（一口气说完不憋）。超长行拆分；连续短句（<5 字 × 4+）标「机关枪节奏」提醒留气口。
4. **书面语听感扫描**：对照 `colloquial-craft.md` 替换表，凡纸面通顺、念出来发死的行逐条标记。
5. **停顿即信息**：转折/揭晓前的停顿写进画面提示行（「（停半拍）」），不占字数但占时长。3min 以上档位要单独留出停顿预算，不要把字数额度填满。

## 10min 档特别说明

10min 口播已接近中视频/B站长内容形态，密度曲线要求放宽为「每 20-30 秒一个价值点或模式中断」；本 skill 仍可管口语化与结构，但分镜/章节设计超出范围。

## 计数复核

声称精确字数前，先把数字、百分比和缩写逐项展开为实际口播读音；百分比包含「百分之」，不能只计数字本身。宿主提供本地只读计算能力时，优先对展开后的口播文本机械计数，再算时长和偏差；不联网、不写原稿。无法可靠复核时明确标「近似」，尤其不得凭未核算的近似值跨越 fatal 边界。
