# Interview Brief 模板

```markdown
## Interview Brief

- 目标岗位 / 公司 / 轮次：（业务面 / 技术面行为部分 / HR 面 / 终面）
- 经历事实账本：已建（导入自 loop-resume-writer 或上次会话）/ 待建
- 在用简历版本：（与账本和原始材料交叉核对；冲突未知就待澄清，不替任何版本圆谎；无则标「无简历在场」）
- 卖点一句话（草稿）：（仅需候选卖点的任务适用；适用时过不了 Gate 就先收敛。反问、职业规划、面试官出题等不需要卖点的任务标 N/A，不阻断。）
- 已知薄弱点：gap / 转行 / 短任期 / 项目角色边界模糊 …
- 距面试时间：（<24h → 建议考前速查模式）
- 目标公司面经（如有，用户自备）：（用于核对题型侧重，本 skill 不提供题库）
```
