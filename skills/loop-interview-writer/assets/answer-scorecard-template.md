# Answer Scorecard 模板

评分与适用性只以 `references/interview-rubric.md` 为准；本模板记录结果，不复制阈值或扩大适用模式。

```markdown
## Answer Scorecard · {题目} · QA revisions: {累计次数／授权预算}
- 类型：故事型／非故事型；面试官设计改用其设计检查表
- 原话、来源、核验状态、角色边界核对：
- 材料未知／相互矛盾：（不据此判候选人造假）
- 与简历比较：范围一致／有依据需修简历／冲突待澄清／无简历

| 适用维度 | 得分 | 满分 | 评分依据（高分与扣分） |
|---|---:|---:|---|
| STAR 完整／结构适配（按类型选一） | | 20 | |
| 具体性与依据 | | 20 | |
| 岗位与任务相关 | | 20 | |
| 事实保真与口径 | | 15 | |
| 时长控制（适用时；估算与目标） | | 15 或 N/A | |
| 口语化（适用时） | | 10 或 N/A | |

- 原始得分／适用满分：
- 归一化方向分：（得分÷适用满分×100；N/A 不记满分或零分）
- Fatal：（引用对应规则及适用范围，或无）
- 判定：Pass／Borderline／Revise
- 材料缺口与下一步：（预算耗尽后仅列问题，不继续改稿）
```
