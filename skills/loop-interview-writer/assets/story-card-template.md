# 故事卡模板

```markdown
## 故事卡 · {故事名} · 来源：账本 E{NN}

- 适用题型：T2 ◎ / T3-冲突 ○ …（映射表同步）
- 一句话版（钩子）：
- 90 秒版（默认应答，≈350 字内）：
  - 锚点行：{关键词 1} → {关键词 2} → {关键词 3} → {R}
  - 展开线：
- 3 分钟版（深挖展开，含决策点与取舍）：
- R 类型：定量／具体定性／真实失败
- R 原话与内容：
- 来源定位／证据支持／核验状态：
- 本人动作与团队结果边界：
- 推算式及输入：（仅有数字推算时）
- 缺料与不可增强的表述：
- 追问预案：
  1. 可能被追：{M1 数字来历} → 答法：
  2. 可能被追：{M2 角色边界} → 答法：
```
