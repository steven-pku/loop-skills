# 面试准备 · loop-interview-writer

[返回系列目录](https://github.com/steven-pku/loop-skills) · [运行指令](SKILL.md) · [验证范围](REVIEW.md)

自我介绍、经历故事、追问与反问准备。适合你已经有真实经历账本、岗位信息和需要练习的问题，希望把下一步做得更明确的情境。

**状态：原发行版本 0.2.3；新分发待验证。** 原版本已有公开发行。迁入同仓不自动增加宿主兼容性或模型行为验证范围。

## 开始前准备

真实经历账本、岗位信息和需要练习的问题。缺失信息可以标记为未知；不要用看似合理的数字、来源或经历填补空缺。请先去除姓名、联系方式和无权分享的材料。

## 你会得到什么

自我介绍、经历故事、追问与反问准备。结果需要由你核对实际材料，再决定是否采用。评分或状态标签只解释本次检查，不代表事实已核实或允许自动采取下一项行动。

## 试一次

以下是合成教学请求，展示如何提供边界；不是本次实测输出。

```text
使用 loop-interview-writer。
请基于我提供的真实经历准备一次项目追问。没有记录的结果标为未知，不帮我补造成功经历。
```

阅读结果时，检查它有没有分开已知事实、推断和缺失材料；有没有保留原输入的限定条件；有没有在需要你补充或确认时停下。

## 适用边界

不冒充真实面试结果；不提供算法或系统设计题解。具体规则以本目录的 `SKILL.md` 与随附资源为准。不要仅复制一个入口文件；运行所需资源要随整个产品目录一起安装。
