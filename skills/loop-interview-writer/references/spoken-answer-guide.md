# 口语化改写（答案是说的，不是背的）

## 判定标准

检查文本是否便于本人说清楚；长句可能增加表达负担，但不据此断言紧张时必然失败。用户实际朗读优先于字数启发式。

## 五条改写规则

1. **短句化**：单句 ≤25 字为宜；>40 字的句子拆。书面嵌套（「基于……的考虑，在……的前提下」）改为先说结论再补条件。
2. **自然连接词**：书面连接（「综上所述/与此同时/鉴于」）→ 口语连接（「所以/当时/后来/最关键的是」）。
3. **第一人称具体动作**：「进行了系统性的优化」→「我把 X 拆成三步，先改了 Y」。动词落地，主语是我。
4. **去成语堆砌与排比**：连续四字格（「攻坚克难、砥砺前行」）全删；排比句式（「不仅…而且…更是…」）拆成平常话。
5. **要点锚结构（替代全文背诵）**：每个答案交付时给两层——
   - **锚点行**：3-5 个关键词（记这个）
   - **展开线**：每个锚点后的自然说法（练这个，不逐字背）
   ```text
   锚点：接手烂摊子 → 先冻结需求 → 两周清完积压 → 单均 X→Y
   ```

## 朗读自检（交付前）

- 出声读一遍：卡壳处＝需要拆的句子。
- 计时：对照 rubric 粗预算并注明是否实际朗读；故事先精简铺垫、保留有依据结果；非故事按其结构裁剪，不强塞 S／T／R。
- 听感测试：像跟同事讲事情，不像念稿——如果有一句「你平时绝不会这么说话」，改掉。
