# 题型骨架（question taxonomy）

> 本文件是**题型分类 + 考察点 + 应答结构**，配自产示例句式；不是题库，不搬运任何平台/机构题文。具体高频题因司因岗而变，考前由用户提供目标公司面经自行核对。

## T1 自我介绍

- 考察点：表达结构 + 卖点清晰度 + 与岗位的自我定位。
- 应答结构：身份定位一句 → 卖点主张 → 1-2 个支撑证据（账本最强条目）→ 与该岗位的连接。
- 三版差异：30s＝定位+卖点；1min＝+最强证据；3min＝+第二证据与动机线。
- 自产示例句式：「我是 X 方向 N 年的从业者，我最拿得出手的是——{卖点句}。最典型的一件事是{E 条目压缩版}。这也是我投这个岗位的原因：{连接}。」

## T2 项目深挖

- 考察点：真实度（是不是你做的）+ 技术/业务判断 + 复盘能力。
- 应答结构：一句话项目定位 → 我的角色边界（诚实）→ 关键决策点与取舍 → 结果 → 一条反思。
- 高危点：角色夸大（mock pass 必追「团队里你具体做哪块」）；数字来历（必追「怎么统计的」）。

## T3 行为面（细分四类）

| 子类 | 典型问法方向 | 应答要点 |
|---|---|---|
| 冲突 | 与同事/上级意见不合 | 立场客观化，落在「怎么推进事情」不落在「谁对谁错」 |
| 失败 | 最大的失败/挫折 | 真实失败与代价；改变及后续验证有材料才写。只有“我太追求完美”先判材料不足／题意未答，不等于造假 |
| 压力 | 多任务/deadline | 优先级判断依据 + 求助与暴露风险的时机 |
| 团队 | 带人/协作/影响他人 | 具体机制（怎么分工/怎么对齐）而非氛围形容 |

- T3 走 STAR，R 可为定量、具体定性或真实失败，必须有具体支持；不强求数字。非故事型 T1／T4／T5 不套此要求。故事从 story bank 取，标记复用。

## T4 HR 面

- 考察点：动机真实性 + 稳定性 + 风险排查。
- 细分：离职原因（不贬前司，落在「要什么」而非「逃什么」）/ 职业规划（与岗位成长线重合）/ 稳定性质疑（短任期：诚实归因一次，不解释三遍）/ **期望薪酬**：只备一个 holding 应答（了解区间+表达灵活+把细节留到 offer 环节），谈判本身不在本 skill 范围。
- Gap／转行：需要时准备简短真实说明，只含用户愿意披露且岗位相关的信息；不强迫交代照护／健康等私人原因，材料相互矛盾先澄清。

## T5 反问环节

- 考察点：判断力与诚意（不是走过场）。
- 按轮次配：业务面问业务（团队当前最大挑战/这个岗位前任的瓶颈）；HR 面问机制（评估标准/成长路径）；终面问方向（业务优先级）。
- 禁区：第一轮就问薪酬福利细节；问官网能查到的信息。
- 备 3-5 条，标注哪条对哪轮。
