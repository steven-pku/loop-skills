# Account Brief 模板

复制后按实际填写。人设锚点是必填项（Gate 问 1）；其余缺项按注释处理。

```markdown
## Account Brief

- 账号与 Gate 上下文：{匿名代称、当前人设／平台／形态／产能，变更时只更新受影响项}
- 平台：{抖音 / 小红书 / 公众号 / B站 / 视频号 / 知乎 / 多平台}
- 人设锚点（一句话）：{具体人群} 关注我，因为我 {独占视角/经历/能力} 能帮他们 {具体收益}
- 受众画像：{年龄段/身份/他们的任务场景}
- 产能自报：每周 {N} 条 × {形态} × 单条约 {N} 小时
- 内容配比策略（可选，无则删行）：{如「教程 40% / 深度 40% / 热点 ≤20%」}
- 本次发布目标（可选，无则默认稳态增长）：{涨新粉 / 稳老粉 / 建信任 / 转化 / 系列铺垫 / 热点响应 / 清库存}
- 数据先例（最好／最差各至多 3 条，以下槽位可重复；不足用实有条数，没有则写〔无先例〕，不强凑）：
  - 表现最好：{标题} · {数据／日期／平台／形态／口径}
  - 表现最差：{标题} · {数据／日期／平台／形态／口径}
- 回避区：{不做的题材 / 风险红线，无则写「无」}
- 本次范围：{日常选题 / 本周规划 / 追某热点 / 盘存量清单}
```
