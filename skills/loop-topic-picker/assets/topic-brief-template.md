# Topic Brief 模板

所有字段均须保留，未知／不适用写明原因。运行时先读 `references/topic-brief-spec.md`；模板不是字段豁免。

```markdown
## Topic Brief · {选题名}

- 选题一句话：{题目方向}
- 账号与 Gate 上下文：{账号代称、有效人设／平台／产能；本轮变更}
- 人设锚点回指：{为什么是这个账号做这题}
- 切入角度：{角度结构型号}——{一句话角度}
- 标题方向 ×3：
  1. {结构型号}：{方向短语}
  2. {结构型号}：{方向短语}
  3. {结构型号}：{方向短语}
- 目标受众动作：{具体讨论、收藏、使用或转发场景}
- 建议形态与成本：{形态、制作时长、用户产能匹配；未知则待补}
- 时效依赖度：{高／中／低及题性理由}
- 核心事件存在：{已确认／未知／被证伪／不适用；精确事实、来源与限制}
- 热度材料：{来源、可复查范围、平台、材料日期、观察窗、口径；无材料如实写}
- 热度状态与支持范围：{已核实／用户提供；充分支持什么；不足另挂〔未核热度〕；常青写时效核验不适用，不声称热门}
- 事实待核附注：{存在以外的具体未核细节、影响与核实动作；无则写无，不能隐去存在未知}
- 发布窗：{有证据的时间范围与制作周期；未知不保证日期；常青写不依赖当前窗口}
- 行动结论：{推荐／条件推荐／不推荐；存在未知的已发生事件不得条件推荐}
- 开工前置动作：{具体补证／素材／产能动作与未满足时处理；无则写无}
- 素材清单：
  - [ ] {素材及来源状态}（易得／难得；是否已具备）
- 系列钩子：{0–3 条后续；无则说明}
- 风险旗：{敏感面、事实／专业边界、隐私处理；无则写无}
- 复评分：{原始得分}/{active denominator}，归一化 {Y}/100
- 评分范围：{逐项列已计维度；未计维度及各自满分；不因得分为 0 删除分母}
- 置信度：{高／中／低及材料覆盖理由，非成功概率}
- Fatal 与循环：{fatal-free 是／否及理由；Loop N/授权上限；剩余问题}
```
