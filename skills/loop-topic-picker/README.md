# 选题筛选 · loop-topic-picker

[返回系列目录](https://github.com/steven-pku/loop-skills) · [运行指令](SKILL.md) · [验证范围](REVIEW.md)

选题比较与 Topic Brief。适合你已经有受众、账号目标、备选题目和可核实来源，希望把下一步做得更明确的情境。

**状态：原发行版本 0.4.1；新分发待验证。** 原版本已有公开发行。迁入同仓不自动增加宿主兼容性或模型行为验证范围。

## 开始前准备

受众、账号目标、备选题目和可核实来源。缺失信息可以标记为未知；不要用看似合理的数字、来源或经历填补空缺。请先去除姓名、联系方式和无权分享的材料。

## 你会得到什么

选题比较与 Topic Brief。结果需要由你核对实际材料，再决定是否采用。评分或状态标签只解释本次检查，不代表事实已核实或允许自动采取下一项行动。

## 试一次

以下是合成教学请求，展示如何提供边界；不是本次实测输出。

```text
使用 loop-topic-picker。
我面向刚开始工作的人，已有三条选题和来源。请比较切入点，缺少热度数据时明确标记未知。
```

阅读结果时，检查它有没有分开已知事实、推断和缺失材料；有没有保留原输入的限定条件；有没有在需要你补充或确认时停下。

## 适用边界

不采集热榜，不把事件存在等同于热度。具体规则以本目录的 `SKILL.md` 与随附资源为准。不要仅复制一个入口文件；运行所需资源要随整个产品目录一起安装。
