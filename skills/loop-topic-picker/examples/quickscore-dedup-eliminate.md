# Example · Quick Score：去重、存在性与淘汰

v0.4.1 合成教学节选，不是行为通过证据。以下事件没有真实指代。

**用户**：第一次租房的人关注我，因为我把信息收集和资料整理做成清单。每周三篇图文，每篇两小时，无历史数据；不做专业法律结论。这五题排一下：①聚合帖称中介甲发生事故的解读；②同一事故下的租客信息清单；③我的租房资料收纳模板；④需驻场二十小时的改造 vlog；⑤同一事故的机构名单。

**模式头**：`Quick Score｜自带五题｜账号甲锚点、产能有效｜未计先例10｜D＝90｜confidence 中，事件项另低`

①②⑤同母题，合并并保留来源差异；用户可否决合并。本例不能确认事故存在，不能只挂待核就推荐事故清单。可另提不依赖该事故的资料整理方向并重评。
