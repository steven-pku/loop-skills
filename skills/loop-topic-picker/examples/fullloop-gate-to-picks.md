# Example · Full Loop：Gate 与专业边界

v0.4.1 合成教学节选，只展示决策节点；没有展示完整池或 Brief，不是端到端运行证明。实际 Full Loop 必须输出真实全池与完整 Brief，不能以本摘要代替。

**用户**：下周选题，我是职场账号。

**Gate**：「职场」尚未回答服务谁、为何关注。请求实际作品与匿名评论主题；零发布账号用冷启动替代三问，不索取整段私信。

**用户补充**：观众想学习如何整理面谈记录与向专业人士提问；我擅长把自己获授权的匿名经历做成记录模板。每周两篇图文，每篇三小时，没有可比较的历史数据。

**锚点提案**：「面临工作变动的人关注我，因为我把记录事实和准备咨询问题的方法做成匿名模板。」用户确认后复用；换账号／定位要使旧锚点失效。

**模式头**：`Full Loop｜无现成清单｜账号甲锚点已确认｜产能2篇×3小时｜未计先例10｜D＝90｜confidence 中`

合适方向可以包括事实记录模板、咨询前的问题清单、获授权经历中的信息整理复盘，分别用教程、观点判断、亲历／系列等真实题型组织。生产时仍须实际展开 15–20 条、逐条打分并展示淘汰，不能宣称这里已跑过。

风险对照：

- 「按这套话术保证拿到补偿／赢仲裁」：无据结果保证，不推荐原承诺；不能把「条件推荐＋咨询律师」当免责。
- 「如何整理面谈记录，区分观察、回忆与待确认事项」：可作为非专业结论的教育题评审；匿名处理，素材真实且授权明确。
- 「某地离职文件的法律效力」：需要匹配地区与时间的可核原文，并明确专业判断边界。缺出处先留待核，不凭记忆补法律结论，也不据材料缺资质就断言用户无资质。

每条入选题的交付必须包含事件存在、材料来源与支持范围、时效依赖、行动和前置动作、完整素材与风险、原始分／active denominator／归一化分／confidence。完整字段以 `references/topic-brief-spec.md` 和 `assets/topic-brief-template.md` 为准。
