# Example · 热度回填不自动解 cap

这是 v0.4.1 合成教学节选，不是模型执行回执，不证明任何真实话题热度。数字仅示范状态与算术；原公开提交保留旧例。

**用户**：无 web。「AI 面试官练习」值得做吗？应届生关注我的图文账号，因为我把面试问题拆成练习。没有历史数据，产能尚未提供。主要想借近期讨论找切口。

**模式头**：`Single-Topic Deep Dive｜单题｜账号甲锚点已给｜未计产能15＋先例10｜D＝75｜confidence 低`

时效依赖中；本题不依赖特定新发布事件，事件存在字段不适用。热度材料缺失，〔未核热度〕。暂定热度 5/20，不声称处于后段或常青。其他教学分：人设 21、差异 15、系列 7，原始 48/75，归一化 64/100。条件推荐，前置动作是核对讨论材料与自身制作能力；不承诺发布窗。

初筛建议：记录目标平台检索词、日期、观察窗和所见材料；新帖密度仅是线索，不能单独证明上涨或过峰。

**用户回填一**：第一页都是近两天内容，我还有热榜截图。

**处理**：来源为用户口述，未见截图内容／口径，〔未核热度〕和 cap 保留，不能改成 17 分。没有新增足以改分的证据，沿用 48/75，不凭一次回填抬分或消耗新循环。

**用户回填二（合成设定）**：补充了可读的连续三个同口径观察窗，讨论量为 100、150、210，均为目标平台同检索词、同样本规则，无重复转载；材料日期覆盖当前窗口。同期独立榜单记录也一致上行。本文练习只解释已有问题类型，不声称某公司发布新产品。每周两篇图文，每篇两小时；素材已备齐，本篇需一小时。

**处理**：仅在这组给定材料范围内支持上行判断，注明「用户提供，本轮未独立核验」，不把合成记录当真实平台事实。教学设定允许热度 17、产能 13；先例仍无，所以 D 从 75 变 90。原始 21＋17＋15＋13＋7＝73，归一化 81.1/100，confidence 中（缺先例）。分母已变，不把 64 与 81.1 说成精密质量增幅；也不保证本周仍热。

若改成完全不依赖热度的练习方法题，必须删除追趋势承诺并另评；不能只换「常青」标签解除 cap。完整交付仍须使用 Topic Brief 的全部字段，本例只演示回填节点。
