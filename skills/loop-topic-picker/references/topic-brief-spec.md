# Topic Brief Spec — 自包含交付字段

本文件是 Topic Brief 字段正本；`assets/topic-brief-template.md` 同步相同字段。步骤摘要或模板路径不免除必填项。每条入选候选独立一份；不推荐题可给诊断卡，不伪装成可开工 Brief。

## 必填字段

```markdown
## Topic Brief · {选题名}

- 选题一句话：{题目方向}
- 账号与 Gate 上下文：{账号代称、有效人设／平台／产能；本轮变更}
- 人设锚点回指：{为什么是这个账号做这题}
- 切入角度：{角度结构型号}——{一句话角度}
- 标题方向 ×3：
  1. {结构型号}：{方向短语}
  2. {结构型号}：{方向短语}
  3. {结构型号}：{方向短语}
- 目标受众动作：{具体讨论、收藏、使用或转发场景}
- 建议形态与成本：{形态、制作时长、用户产能匹配；未知则待补}
- 时效依赖度：{高／中／低及题性理由}
- 核心事件存在：{已确认／未知／被证伪／不适用；精确事实、来源与限制}
- 热度材料：{来源、可复查范围、平台、材料日期、观察窗、口径；无材料如实写}
- 热度状态与支持范围：{已核实／用户提供；充分支持什么；不足另挂〔未核热度〕；常青写时效核验不适用，不声称热门}
- 事实待核附注：{存在以外的具体未核细节、影响与核实动作；无则写无，不能隐去存在未知}
- 发布窗：{有证据的时间范围与制作周期；未知不保证日期；常青写不依赖当前窗口}
- 行动结论：{推荐／条件推荐／不推荐；存在未知的已发生事件不得条件推荐}
- 开工前置动作：{具体补证／素材／产能动作与未满足时处理；无则写无}
- 素材清单：
  - [ ] {素材及来源状态}（易得／难得；是否已具备）
- 系列钩子：{0–3 条后续；无则说明}
- 风险旗：{敏感面、事实／专业边界、隐私处理；无则写无}
- 复评分：{原始得分}/{active denominator}，归一化 {Y}/100
- 评分范围：{逐项列已计维度；未计维度及各自满分；不因得分为 0 删除分母}
- 置信度：{高／中／低及材料覆盖理由，非成功概率}
- Fatal 与循环：{fatal-free 是／否及理由；Loop N/授权上限；剩余问题}
```

## 字段纪律

- 所有字段必填；未知保留具体缺口，不适用说明原因，不用空白掩盖未核状态。
- 事件存在、材料来源、充分性互不替代。存在未知／被证伪的事件不得列为推荐或条件推荐；真实重塑后另评，不沿用原分。
- 条件推荐必须带可执行的开工前动作；事实核实与素材计划尚未执行，不写成已经完成。难得或关键材料未具备时不能宣称可以直接开工。
- 分数展示原始值、active denominator、归一化值、已计／未计维度和置信度。仅缺先例用 90，仅缺产能用 85，同时缺两者用 75；其他情形从已计满分实际求和。
- 复评分必须有真实修订或新增证据；不靠改措辞凑门槛，初评／复评共享同一 Loop 编号。
- 标题方向是短语提案，不写整篇正文。风险旗记录具体专业断言、来源或授权缺口，不猜用户资质；公开资料教育可评审，不把它等同个人法律／医疗／金融建议或结果保证。
- 常青不等于没有事实风险，未核事件也不等于常青。发布日期建议与经证据支持的发布窗分开。

## 下游使用

Brief 可交给用户选择的写作流程，也可独立使用。没有安装其他 Skill 仍可完成本产品的选题交付；移交不自动授权写稿、发布、登录或外发。发布后只用真实、来源明确的回填校准先例；合成演示不能变成真实账号数据。
