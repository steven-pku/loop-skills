# Angle Playbook — 切入角度结构库

以下结构是设计工具，不是点击、完播或信任效果的已验证机制；实例须由材料支持。精修 top 候选时用。角度不是标题——角度是「这题我讲什么别人没讲的」的一句话判断；标题方向是角度的包装草案（最终标题归写作类 skill 定稿）。

## 角度结构（9 型）

每型给结构＋适用条件＋风险。给候选配角度时先判哪型贴合人设，禁止全部 top 候选同一型。

### 1. 重新定义型

`{X} 不是 {大家以为的标签}，是 {Z}` —— 把议题从工具层拔到判断层。
适用：观点/判断类人设；话题被普遍浅读时。风险：Z 立不住就是装深刻；Z 必须能用内容撑满。

### 2. 反共识型

`都说 {X}，其实 {Y}` —— 用可验证的反例对抗主流叙事。
适用：有一手经验或数据支撑 Y 时。风险：为反而反＝失信；配速纪律——反共识做多了人设会变成「杠精号」，隔几期一条。

### 3. 信息差型

`{圈内已知、圈外未知} 的 N 件事` —— 做跨圈搬运的理解中介。
适用：人设自带跨圈身份（既懂 A 圈又服务 B 圈受众）。风险：纯搬运无加工缺少账号自身贡献；必须加「对你意味着什么」层。

### 4. 亲历评测型

`我真金白银/真实时间试了 {X}，结论是` —— 以真实亲历材料组织评测。
适用：任何人设，须有实际亲历可展示。风险：成本造假会被拆穿；亲历细节（花了多少、卡在哪）就是内容本体，不能省。

### 5. 避坑清单型

`{做某事} 前必知的 N 个坑` —— 明确任务与风险。
适用：受众有明确任务场景（装机/报税/选课）。风险：坑必须真踩过或真核实过，编的坑一条就毁清单信用。

### 6. 步骤复现型

`N 步做出 {结果}，可直接照抄` —— 展示可复现步骤。
适用：教程/实操人设。风险：步骤必须真能跑通；避免承诺完整而遗漏关键步骤。

### 7. 数字承诺型

`N 个 {X}，第 {K} 个最值` —— 明确内容范围。
适用：清单体裁通用。风险：N 虚胖（凑数条目）缺实质价值；N ≤ 观众一次能消化的量。

### 8. 权威关联型

`{权威人物/机构} 刚 {动作}，意味着什么` —— 借权威事件做解读。
适用：解读/评论人设。风险：只转述不解读＝新闻搬运（死亡模式）；解读部分才是「为什么是我」。

### 9. 造概念型

`{现象 A}、{B}、{C}，标记了 {你命名的范式}` —— 把散点现象提炼成可命名的判断，立观察者人设。
适用：深度/思想类人设，须说明概念能解释哪些后续问题。风险：概念空转（起了名字没有内容）；一期立不住的概念别硬造。

**取结构、弃挑衅**：以上结构都可配平实语气；「你还在 X 就输了」式挑衅腔不取——不把刺激性措辞当作效果保证。

## 标题方向法（每条 top 候选出 3 个方向）

3 个方向从不同结构里取（如：一条重新定义＋一条数字承诺＋一条亲历），给写作环节留选择余地。方向是短语不是成品：

- 写「方向：反共识——大家都在夸 X 的角度，切它没人说的成本面」
- 不写最终标题文案（字数、平台规则、禁标点等归写作类 skill 管）

## 素材清单法

每条 top 候选列开工前要收集的素材，逐项标「易得/难得」：

- 易得：自己已有的数据/截图/经历、公开可查的一手来源
- 难得：需要采访/实测周期/花钱买的素材
- 难得项 ≥ 半数 → 回头核产能匹配分是否打高了（素材获取成本是制作成本的一部分）
