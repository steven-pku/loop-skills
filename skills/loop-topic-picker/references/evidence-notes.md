# Evidence Notes — 设计选择与外部事实

本候选没有携带足以逐条复核平台机制或工具比较的当前原文。本轮未联网；删除无证据的通用比较及确定性机制断言，不按记忆补来源。

## 设计选择

- 人设 25、热度 20、差异化 20、产能 15、系列 10、先例 10：用于本工具的取舍框架，非实证最优，不声称符合行业权重或具有独占维度。
- 80 左右的参考线、未核热度 cap 12、常青 12–16、分差严格小于 5：内部诊断约定，不是流量成功率、统计显著性或平台门槛。
- 人设 Gate、产能检查、宽池淘汰、角度结构：产品设计方法，不由教学示例证明实际效果。
- 评论、收藏、转发等受众动作可作为创作目标；不推定任何平台算法给它们的相对权重。

## 外部断言的证据要求

需要断言某平台机制、发布时效、算法效果或同类工具能力时，先取得可定位原文，记录作者／发布方、链接、日期、适用平台和原文实际支持的范围。官方原文与媒体转述分列；二手摘要不可标成一手，也不能把一个平台的结论扩至所有平台。

没有这些依据就标〔待核〕或不作该断言。尤其不要从「非实证最优」的免责声明跳到「独有」「普遍更好」「平台必降权」等事实结论；不为满足格式编造比较样本。
