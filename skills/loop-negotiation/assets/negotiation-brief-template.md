# Negotiation Brief（模板）

指引见 `../references/brief-guide.md`。Gate 未过不能靠填模板生成完整卡组；未知／不适用保留理由。

```markdown
## Negotiation Brief
- 场景与模式：
- 对方角色及已知权限；专家经验依据／未知：
- 薪酬体制：市场化 / 已确认刚性带宽 / 未知 / 不适用（依据）
- Downside check：谈崩的实际代价、可承受性及低风险边界：
- 关系与时间约束；期限来源：
- BATNA：真实可执行选择及必要成本范围：
- 硬底线与触线动作：
- Gate：通过 / 未通过 / 拒答；拒答仅低风险地板，非完整卡组
- 理想／满意／底线：每层注明个人选择或事实依据

### 数字与来源
| 编号 | 个人目标／自有事实／市场主张 | 值与口径 | 来源归属 | 本轮核验状态 | 日期／同岗／代表性 | 允许使用范围 |

### 对方视角

- 可交换议题：逐项可行／未知／不适用；不编项目凑数

- 报价信息状态：充分 / 不对称 / 对方先问 / 对方已报价 / 不适用
- 报价分支：先报 / 后报 / 反锚 / 不适用；理由及点价／范围精度依据：
```
