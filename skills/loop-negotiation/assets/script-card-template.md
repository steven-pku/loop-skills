# Script Cards（模板）

依 `../references/script-card-patterns.md` 使用，只引用 Brief 允许使用的事实和明确个人目标。Gate 未过仅填低风险地板，不套完整卡组。

```markdown
## 谈判话术卡
- 状态：完整候选 / 未经 BATNA 校准，非完整卡组
- BATNA 与内部底线：已知 / 未知（不默认向对手披露）
- QA 累计：N/limit

### 低风险地板（拒答 Gate 时只用本节）
- 开场：
- 信息问句：
- 暂停／退出句：
- 两项未答 Gate 问题：
（禁止数字锚、让步阶梯及摊牌）

### 完整候选（仅 Gate 已过，按场景选择）
- 开场：
- 报价分支：先报 / 后报 / 反锚 / 不适用
- 点价／范围／非金额诉求：
- 依据类型、核验状态与允许使用范围：
- 异议卡：对方可能说什么 → 回应与转向 → Brief 依据
- 交换阶梯及底线触发动作：
- 收尾：确认事项、记录需求、真实下一步
- 〔待核〕事实：保留内部，不能变已核市场价
- Mock：已跑 / 压缩 / 未跑 / invalid；实际证据
- 未解风险 ID、用户实际确认与 Revise / risk accepted 状态：
```
