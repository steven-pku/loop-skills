# QA Scorecard（模板）

权重和方向线是设计启发式，不是统计校准。缺 Brief、未知与不适用须区分，不能填勾冒充通过；详见 `../references/negotiation-rubric.md`。

```markdown
## QA Scorecard · QA loop: N/limit
- 模式／评分对象／材料范围：
- Gate 状态：通过 / 未通过 / 拒答；低风险地板不算完整卡组

### 真实性与筹码审计
| 项目 | 通过／确认缺陷／未知／不适用／缺 Brief | 证据与原因 |
|---|---|---|
| 主张可回溯 Brief | | |
| 个人目标与市场事实分开；来源不冒充核验 | | |
| 无虚构筹码 | | |
| 卡面与底线、阶梯一致 | | |

### 评分
| 维度 | 得分或未知／不适用／缺 Brief | 满分 | 原句依据 |
|---|---|---|---|
| 目标三层与底线 | | 20 | |
| 对方视角 | | 20 | |
| 阶梯与交换 | | 20 | |
| 开场与先报／后报／反锚 | | 15 | |
| 异议应对 | | 15 | |
| 语气与关系 | | 10 | |

- Fatal：无 / 编号＋已确认原句；未知不当编造
- 方向：Pass / Borderline / Revise / incomplete

### 风险与模拟
| 风险 ID | 内容／是否可接受 | 用户明确确认原话或未确认 | 保留状态 |
```
