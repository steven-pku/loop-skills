# 中文职场谈话准备提示

本文件是供选择的准备提示与模拟情境，不是已证明的中国职场普遍规律。制度、权限与可协商项逐家公司确认；不使用无来源的成功率、涨幅、期限或可靠度排名。法律适用问题交对应法域的专业渠道。

## 可能出现的询问与应对

| 对方动作 | 待确认事项 | 准备方向 |
|---|---|---|
| 先问期望薪资 | 是面试筛选还是录用意向已明确后的议价 | 按任务阶段分流；本件内可询问结构，或表达有依据的个人目标；无证据不报“市场价” |
| 要流水／截图／完整 offer | 用途、必需字段、接收方、保管和可否替代 | 不默认提供或承诺稍后上传；可拒绝、延后或询问最少证明形式。确有必要由用户明确选择范围和渠道；不收第三方身份，不伪造收入。模拟索证不产生真实上传授权 |
| 用总包介绍报价 | 固定／浮动／福利、周期与条件 | 分列核对；书面记载有助确认，但不替代对条款适用性和可执行性的专业判断 |
| 称带宽固定 | 哪部分固定、谁有权限、有无复议机制 | 询问真实可交换项，不假定签字费更容易批或职级必然更值钱 |
| 口头许诺未来调整 | 条件、负责人、时点、是否愿意确认 | 请求明确记录；未落实就标不确定，不能当保证，也不凭拒绝落字断定欺骗 |
| 给出答复期限 | 原期限、能否延期及实际替代方案 | 请求合理时间，不凭紧迫语气判断截止日真假，也不虚构其他流程 |

## 关系与隐私

- 不使用同事可识别的薪资资料作施压工具；可讨论本人职责、公开岗位条件或经授权且范围有限的资料。公司是否有保密规定须核实，不作“多数公司”断言。
- 沟通路径按已知制度与利益冲突选择；先确认直属、HR 或申诉渠道的作用，不把任何越级都判断成关系破坏。
- 试用期能否讨论调整依已知职责、约定和流程判断，不声称“几乎无成功案例”。可以询问评估标准和职责变化的处理机制。
- 真实 offer 只在用户允许的范围内使用；不公开他人或公司非必要信息，不编造，不用情绪化离职威胁。
- 体制内、国企或大企业名称本身不证明带宽完全刚性。只有用户确认具体限制后，才调整 package 预案。

## Offer 细节核对清单

按本次必要范围选用：固定薪酬与发薪周期、浮动部分条件、签字费及返还条件、期权授予条款、职级、福利、社保公积金口径、年假、工作安排、review 条件、到岗及前置条件。竞业、解除、补偿等法律效果不由本 skill 判断。不要为了填全清单索取整份私密材料。

## 补数据的方法

没有“48 小时必能补齐”或“朋友数据最硬”的排序。可核查用户可合法提供的自有资料、公开招聘信息和明确出处的岗位调研；按日期、城市、岗位层级、固定浮动口径、样本量与选择偏差判断支持范围。

第三方个例须有使用权限并保护身份；猎头或社区资料记录归属与不确定性，多个说法不能简单取交集就变真。公开 JD 是报价范围，不自动等于成交价。补不到就保留〔待核〕，询问结构、争取时间或表达真实个人目标。

## 语域

可以用“了解、对齐、商量”降低敌意，也允许明确坚定地说出不能接受的条件。词语本身不保证关系结果；根据用户语气与场景选用。感谢对方的具体帮助，不以迎合换取虚假承诺。
