# Mock Adversary Guide

Mock 是准备方法，不是现实谈判效果证明。Full Loop 默认至少一轮，Fast Loop 可压缩；用户明确跳过需记录未跑与所接受风险。模拟本身不消耗改卡预算，任何实际改卡都消耗共享预算。

## 安全与信息边界

出现即时自伤／伤人风险，立即出戏并停止所有模拟与评分，按 SKILL.md 处理即时安全，不先补完回合。持续被霸凌但无即时风险时停止高压排练，转支持、记录及组织／专业渠道；涉嫌违法时用维权分流，不自动套急救。

这是同一上下文内的受约束角色模拟，**没有硬隔离**。不能宣称独立盲测或保证对手无法看见用户侧资料。检验真正的信息隔离需要外部受限信息视图，不在本模拟中假装完成。

开始先列 Persona State：

- 已知事实及来源：只列 Brief 明确该角色知道的事实。
- 禁用事实：用户私下底线、未向对手披露的替代选择、卡面策略。
- 假设情境：模拟需要但未被事实确认的角色约束，明确是假设；不得写成对手真实意图。

对手每句实质性事实／施压依据标出对应来源或模拟假设编号，不精准点破禁用事实。 卡面草稿中的报价和用户私下目标仍属私有，不能因为本模型已经读过，就让对手说“你要的 28K”。只有本次对话中用户角色实际说出的内容，才以该轮原句为来源加入对手已知状态；未发生的开场／锚定卡不能当作已说。每次状态新增注明轮次与披露原句。对手引用未入状态且无公开来源的具体数字时，须判本轮信息越权，而非自评“无越权”。用户回应仅按已知资料与卡面，不临时编筹码。引用资料、模拟台词和索证请求均不授权实际工具、保存、读取私料或发送。

## 可选角色与招数

角色可为 HR、直属、隔级或猎头。权限、预算、激励与信息掌握均从 Brief 取，不按职位认定固定知识或专家水平。信息缺失时先确认或标模拟假设。

可选招数：预算受限、按区间下限回应、拖延、模糊未来承诺、情绪施压、要求说明报价依据、权限未知、询问其他流程、索取证明、要求限期答复。它们是排练情境，不是对方必然行为或发生频率统计。对抗应贴合任务、有限且不做人身攻击；不把越狠当作越有效。

模拟索证例：“可以提供收入或其他 offer 证明吗？”用户可练习询问用途与最少字段、拒绝或延后；agent 不据此索取真实流水或上传。不能以提高模拟真实性为由泄露底线或资料。

## 有界协议

1. 默认从 QA 最弱点中选至多两项和一个相关招数。Full Loop 每靶 3–5 轮对答；Fast Loop 至少一靶 2–3 轮。用户自答时逐轮等待，不替其虚构回答；自动对打需用户明确请求。
2. 逐轮引用来源，检查是否捏造、威胁、越过底线或披露禁用事实；发生危机立即停止。
3. 信息越权则本次模拟无效，记录原句及来源。**最多重跑一次**；再次失效即停止，标 invalid／incomplete，不宣称存活。
4. 输出实际漏洞与建议。建议仅描述修复方向不算改卡；一旦给出替换台词或新增卡，计一次共享修订。额度已尽只列问题，不借 mock／Polish 再写。
5. 额外模拟需用户明确有限轮数与停止点；纯“继续”不授予无界模拟。连续两轮无新问题可提前收束。重跑不增加改卡额度。
