# Scenario Guide — 五场景准备骨架

下列是可选准备结构，非普遍职场规律。已公开的合成行为证据及未测范围见 `../REVIEW.md` 与版本验收记录，不代表五场景全覆盖。Gate 地板、危机与隐私边界先于所有场景卡型。

## 1. Offer 谈薪

- 已明确录用意向或已有 offer 才进入本件议价；此前筛选阶段的薪资问答转面试准备。
- 明确当前报价、期限与可讨论项；不声称某个时点必然最有杠杆。
- 卡组可含开场、报价分支、异议应对、收尾；练习预算、模糊承诺、要求说明依据等情境，不把其视为必然套路。
- 不虚构当前薪资或其他 offer，不将待核市场价写成事实。可讨论真实存在的 package 项，不假定签字费更容易批。

## 2. 在职加薪

- 先确认实际预算／绩效时间与职责变化，不固定要求提前 4–6 周或断言某种时点必失败。
- 用用户真实成果和职责依据准备；正式述职文稿另作交接，本件不依赖其他 skill 才能继续。
- 不使用第三方可识别薪资施压；可询问自身薪酬复核机制、公开岗位条件与职责匹配。不把工资差异本身当充分因果论据。
- **禁止离职威胁作为任何阶段的技巧**，真实 BATNA 也不豁免。坚定正例：“如果这些条件暂时无法满足，我会按已评估的另一选择安排；谢谢你愿意讨论。”情绪胁迫反例：“不给我加就等着项目出事。”前者需要真实选择支撑，后者不可写。
- 弱而真实 BATNA 可正常过闸，语气与交换按事实校准；可询问 review 条件，但不把它当保证加薪。

## 3. 拒绝与婉拒

- 可用缓冲、客观理由、真实替代选择；明确决定而不贬低对方。
- 通常去金额锚定卡，以开场、异议应对和收尾为主；没有可行替代时诚实说明，不编造。
- 不将拒绝本身视作威胁，也不机械以道歉次数裁定立场。

## 4. 提离职

- **不把正式书面通知当试探性筹码**。通知的送达、解除时点、撤回条件及其他法律效果需按具体法域、合同与事实专业核验；本件不作通用实体法判断。
- 用户已决定离开时准备决定、交接和确认事项；若其实要谈加薪，回场景 2，不用递通知试探或制造威胁。
- 对 counteroffer 先澄清用户愿意重新考虑的条件，不断言接受后必失去信任或被优先替换。
- 薪资扣留、证明争议等涉嫌权利侵害时停止普通谈判准备并转专业渠道。咨询入口不等于办理程序、立案或保全期限；不能替用户宣布手续已完成。

## 5. 坏消息传达

- 可用“事实—影响—已做处置—需要的决策”，先把已知事实说清，未知处直接标注。
- 卡组以开场、疑问回应和决策请求为主，不强行谈 package。
- 不能为了完整性编造处置或承诺；可以明确目前尚无方案、需要何种决策与资源。
- 拒绝是边界选择，坏消息是事实已发生；混合任务先分清事实与待决定项。
