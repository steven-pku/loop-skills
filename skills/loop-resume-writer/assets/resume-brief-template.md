# Resume Brief 模板

```markdown
## Resume Brief

- 目标岗位 / JD：（原文粘贴或链接；无 → 先走目标岗位 Gate）
- 候选人阶段：应届 / 1-5 年 / 5 年+ / 转行
- 交付形态：平台在线简历 / 附件 PDF / 双形态
- 现有简历：有（附原文）/ 无（从账本新建）
- 经历事实账本：已建（导入）/ 待建
- 硬约束：页数上限 / 敏感项（竞业、gap 说明口径）/ 不可写内容
- 已知差距：JD 中自知不满足的项（先说，省一轮映射）
- 缺失材料：
```

填写规则：目标岗位为空时不得开始改稿；「已知差距」由候选人自报 + 映射矩阵补全。
