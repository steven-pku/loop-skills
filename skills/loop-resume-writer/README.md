## 开始前准备

真实经历、目标岗位和可提供的成果证据。缺失信息可以标记为未知；不要用看似合理的数字、来源或经历填补空缺。请先去除姓名、联系方式和无权分享的材料。

## 你会得到什么

事实账本、岗位匹配和中文简历表述。结果需要由你核对实际材料，再决定是否采用。评分或状态标签只解释本次检查，不代表事实已核实或允许自动采取下一项行动。

## 试一次

以下是合成教学请求，展示如何提供边界；不是本次实测输出。

```text
使用 loop-resume-writer。
我参与整理了客服常见问题，但没有转化率数据。请先做事实账本，再给出不虚构效果的简历表达。
```

阅读结果时，检查它有没有分开已知事实、推断和缺失材料；有没有保留原输入的限定条件；有没有在需要你补充或确认时停下。

## 适用边界

不补造数字，不把参与写成主导；英文 ATS 简历不在范围内。具体规则以本目录的 `SKILL.md` 与随附资源为准。不要仅复制一个入口文件；运行所需资源要随整个产品目录一起安装。
