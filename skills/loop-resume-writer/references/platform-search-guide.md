# 平台在线简历优化（Boss直聘等）

> 证据等级声明：本文为 practitioner consensus（从业者共识）级，非平台官方口径。平台机制随版本变化，本文具体宣称按「经验假设，需用户按目标平台实际情况自行验证」对待，不作平台机制的确定性断言。依据边界见 evidence-notes.md；不把任何平台排序或 ATS 拒绝机制当作已验证事实。

## 优化原则

1. **技能词具体化**（共识度高）：HR 按具体词搜索。「精通 Python」→「PyTorch 模型训练与部署实战」；「做过电商运营」→「天猫大促全链路运营（预售/爆发/返场）」。具体化的前提是账本里真有——**与经历无关的关键词堆砌＝造假，本 skill 不做**（市面攻略教「埋点不需符合实际经验」，那条路不走）。
2. **岗位期望与目标 JD 对齐**：求职期望的岗位名用行业通行叫法，不自创头衔。
3. **首屏三要素**：当前/最近角色、核心技能组、一句话定位——平台卡片视图通常只露前几行（经验假设，各平台版式不同，以目标平台实际为准）。
4. **个人简介区**：2-3 句，角色+年限+最强有来源成果（定量或具体定性）+目标方向；不写求职宣言体（「希望找到一个能发挥我价值的平台」）。
5. **活跃度**（共识度中）：从业者普遍反馈更新简历可提升曝光；机制无官方口径，作为提示告知用户即可，不写进简历本体策略。

## 与 PDF 版差异

| 维度 | 平台在线版 | 附件 PDF 版 |
|---|---|---|
| 优化对象 | 搜索命中 + 卡片首屏 | 筛读动线 + 版面 |
| 技能表述 | 按搜索词具体化 | 按叙事完整性组织 |
| 长度 | 平台字段限制内做满关键区 | 一页纪律 |

两版事实同源（账本），禁止两版数字不一致。
