# QA Scorecard 模板

```markdown
## QA Scorecard · QA loop: {1/2 或 2/2}

### 真实性审计（先跑，不过不打分）
- 成果/数字逐条可定位到账本：通过 / 问题清单：
- 〔待补数据〕未变实数：通过 / 违例位置：
- QA Only 无独立账本：只查内部一致性与可疑数字，无法核验的成果标「存疑」；不视作真实性通过。

### 六维评分
| 维度 | 得分 | 满分 | 扣分举证（引用原句） |
|---|---:|---:|---|
| 成果导向 | | 25 | |
| 数据支撑 | | 20 | |
| 读者对齐 | | 15 | |
| 结构 | | 15 | |
| 语言（语域档：{企业/外企/体制内}） | | 15 | |
| 风险与求助 | | 10 | |
| **合计** | | **100** | |

### Fatal issues
- [ ] 编造成绩数字（含〔待补数据〕变实数）
- [ ] 全篇动作无结果
- [ ] 全篇无量化且未标〔待补数据〕
- [ ] 述职/答辩无案例支撑
- [ ] 与账本冲突（进行中写成已完成等）

### 判定
- 结果：Pass（无 fatal 且六维明显扎实）/ Borderline（无 fatal 但一两维明显弱）/ Revise（任一 fatal 或整体明显弱）
- 分数仅作方向性诊断，约 85 分是参考，不按一分差或窄分带裁决。
- 到 2/2 轮：交付当前最佳稿，列未解决缺陷与素材缺口，交还用户。
- 修订规则（每条指到具体句子 + 账本条目）：
  1.
  2.
```
