# 素材追问清单模板

> 用途：Gate 失败的 fast iteration、账本缺量化、用户说「这周没干啥」。问题必须具体到可直接回答，一次 ≤5 条，按对本次读者的重要性排序。

```markdown
## 素材追问清单（回答后直接升级账本）

针对你列的事项，逐条补这几个空：

1. {事项 A}：它改变了什么？谁感知到了这个变化？
2. {事项 A} 的数字：{指标} 从多少到多少？（转化率/耗时/成本/单量/人数，选贴近的）
3. {事项 B}（进行中）：推进到哪个里程碑？阻塞在哪，预计何时解除？
4. 本周期你拦下过什么坑 / 帮过谁的忙 / 沉淀了什么后续能复用的东西？
5. （述职/晋升）这件事里你个人的角色边界是什么？团队整体结果是什么？
```

常用指标提示（帮用户想起来，不是替用户填）：时间（处理时长/交付周期）· 钱（营收/成本/预算）· 量（单量/用户数/覆盖人数）· 质（错误率/满意度/SLA）· 率（转化/留存/复购）。
