# Report Brief 模板

```markdown
## Report Brief

- 场景：周报 / 月报 / 季度·年终总结 / 述职 / 晋升答辩 / 项目复盘
- 读者：直属上级 / 隔级及以上 / 晋升委员会 / 跨部门（多读者时标主读者）
- Value Gate 问 1（本周期创造的可感知价值，一句话）：
- Value Gate 问 2（读者拿这份汇报做什么判断/决策）：
- 语域档：企业（默认）/ 外企 / 体制内（或：用户样本 few-shot）
- 目标层级要求（仅述职/晋升，用户提供）：
- 组织固定模板：有（贴入）/ 无（用 scenario-guide 骨架）
- 成果账本：已建 / 待建
- 已知约束（篇幅上限、敏感事项、不可写内容）：
```
