# 证据分级说明（evidence notes）

> 本 skill 引用的结构/公式断言按三层诚实标注：一手出处 / practitioner consensus / 经验规则。禁伪造出处。引用时按下表口径，不升级证据等级。

| 断言 | 层级 | 引用口径 |
|---|---|---|
| 结论先行/金字塔结构、MECE、SCQA | **一手**：Barbara Minto《The Pyramid Principle》（1985 初版；1996 修订版《The Minto Pyramid Principle》）。方法成型于其 McKinsey 任期（1963-1973） | 直接引书名+框架名；不写死页码 |
| 成果 X + 度量 Y + 手段 Z（XYZ 公式） | **一手**：Laszlo Bock《Work Rules!》（2015）及其公开求职建议 | 直接引用；与 loop-resume-writer 共锚，场景互斥（在职汇报 vs 求职材料） |
| STAR 框架（Situation-Task-Action-Result） | **practitioner consensus**：DDI 自述 1970s 随行为面试法带入市场，vendor 起源、无独立学术出处；大学就业中心广泛采用 | 标「行为面试法传统下的从业者共识框架」 |
| 强动词+语境+量化结果 改写公式 | **practitioner consensus**：多家大学就业中心（Yale/Columbia/Princeton/UC Davis 等）指南收敛一致 | 标从业者共识 |
| 「读者拿汇报做决策」的功能观 | **经验规则**：本 skill 的设计立场（Value Gate），无外部出处主张 | 作为方法论立场陈述，不冒充研究结论 |
| 「67% 管理者不满周报」「76% 信息过载」类统计 | **无源传言**：仅见内容聚合站，无原始调研可溯 | **不采用**，任何输出不得引用 |
| 各大厂职级晋升的具体要求 | **社区二手 + 时变**（2025 年阿里/腾讯/字节职级体系均在改革） | 不进本 skill 任何文件；目标层级要求由用户提供，skill 只给通用跃迁信号框架（scenario-guide.md） |
