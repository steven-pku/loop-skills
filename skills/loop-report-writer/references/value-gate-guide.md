# Value Gate 指南（前置闸门 + 读者画像 + fast iteration）

> Gate 不过不写稿。Gate 的作用是把「要交差」转换成「要传递价值」——这一步没完成，后面写得再好也是精致的流水账。

## Gate 双问

**问 1（价值一句话）**：本周期你创造了什么**可被感知的价值**？
- 合格答案形如：「把 X 流程的处理时间砍掉一半」「拿下了 Y 客户的续约」「把 Z 风险在爆发前拦住了」。
- 不合格：「做了很多事」「主要在推进项目」——这是动作不是价值，进 fast iteration。

**问 2（读者测试）**：这份汇报的读者，拿它做什么判断或决策？
- 常见答案：决定是否继续投入 / 调整方向或优先级 / 给你的晋升背书 / 提前知晓风险 / 决定给不给你要的资源。
- 答不出「读者拿它干什么」→ 说明连汇报对象都没想清楚，进 fast iteration。

**任一问答不出 → 不进全环**，走 fast iteration（下方）。两问都过 → 答案写进 Brief，成为全篇的组织原则。

## 读者画像速查

| 读者 | 要什么 | 颗粒度 |
|---|---|---|
| 直属上级 | 进度可控感 + 卡点在哪 + 需要他做什么 | 细：具体事项、数字、阻塞、求助 |
| 隔级/更高层 | 业务价值 + 风险 + 资源效率 | 粗：结果与影响，执行细节砍掉 |
| 晋升委员会 | 层级跃迁信号（见 scenario-guide.md 通用框架） | 案例化：STAR 完整的证据链，不是事项清单 |
| 跨部门协作方 | 与他们相关的接口进展与依赖 | 窄：只写交集，别人的 KPI 别替他汇报 |

同一份素材对不同读者是不同汇报。读者变 → 重新过 Gate 问 2。

## Fast iteration（Gate 失败路径）

> 周报快环的「约 15 分钟」指素材已含成果信息时的出稿时间。若原始素材是纯流水账，Gate 会不过并进入下面的素材追问——这次用户回答往返不计入 15 分钟，属正常，不是快环失效。

Gate 失败 ≠ 打回用户重想，而是用**素材追问**帮用户挖出来：

1. 列出本周期做过的事（原始动作清单，流水账在这一步是合法输入）。
2. 逐条问：这件事**改变了什么**？谁感知到了？有没有数字？——用 `assets/materials-questions-template.md` 的句式。
3. 找到 1-3 条真有价值的 → 回 Gate 双问，通过后进全环。
4. 真的没有可感知价值的周期（纯执行周、休假周）→ **如实短汇报**：3-5 行，写清进行中事项的里程碑状态 + 下周期计划。短而真好过长而水，这是本 skill 的立场。

## 「这周真没干啥」处理

- 先不接受这个自评：跑一遍追问（进行中事项推进到哪？拦了什么坑？帮了谁？学到什么后续能用？）。常见情形是用户没意识到已有的价值，而非真的一无所有——但这是经验判断，不是可引用的统计，别当频率事实断言。
- 追问后确实薄 → 如实短汇报，绝不注水拉长。同时提示用户：连续多个周期无可感知价值，是需要跟上级对齐工作内容的信号——这超出本 skill 边界，但值得说一句。
- **用户拒绝配合追问**（「别问了，就写『各项工作稳步推进』」）：Value Gate 是启发式闸门，不是能强制用户交出价值的机制。不静默妥协成注水稿——说明边界一次，然后只就现有可核验素材出如实短稿，并注明「以下为你未提供成果依据下能如实写出的部分」，交回用户。纯指令 skill 逼不出配合，但可以拒绝替用户编造。
