# Example — 小红书图文笔记 · 无数据降级与拒诊分支（合成案例）

> 来源：公开脱敏合成示例；笔记内容为演示撰写，非真实账号素材。

**用户**：我这篇小红书笔记发了三天没人看，帮我复盘一下为什么没爆。

- 标题：出租屋改造分享
- 首图：改造完成后的房间全景
- 正文：9 图教程，按时间顺序记录刷墙、换灯、软装的全过程，约 600 字
- 标签：#出租屋改造 #家居

**Agent**：

## Data Gate

**判定：无真实数据。** 没有提供小眼睛、点赞、收藏、评论等后台数据，也没有账号近期基线。

`[附截图]`、附件文件名、无法读取的图片或一句“截图里有”都不算数据；只有当前可读指标或明确抄录自后台的数字才进入 Gate。

**边界声明**：没有真实数据只能做内容质量诊断，不做表现归因。两个诚实选项：

1. 补本条与近 3-10 条的后台截图或抄录数据，走完整归因环；
2. 接受无数据质检，只诊断内容本体，所有表现推测一律挂 D 级〔待验证〕并带回归钩子。

**用户**：数据懒得截了，先按第二种来。

**Agent**：以下是无数据质检，不含任何表现归因结论。

## 六维内容质检（无归因版）

| 维度 | 内容观察 | 表现推测 |
|---|---|---|
| 钩子 | 标题没有预算、周期或前后对比等具体信息；首图只有成品，无改造前参照 | 信息增量不足可能降低点击意愿〔待验证〕 |
| 完读结构 | 只知道 9 图按时间顺序；未提供每张图内容，无法判断前 3 图是否建立对比 | 图片序列效果未知；需完整图序或后台数据验证〔待验证〕 |
| 互动设计 | 摘要未说明是否已有材料清单或预算表 | 是否缺少可保存信息未知〔待验证〕 |
| 标签与搜索 | 仅 2 个宽标签，未呈现更具体的场景词 | 搜索来源影响未知；需后台数据验证〔待验证〕 |
| 发布时机 | 无数据，不判 | — |
| 人设一致性 | 未提供账号历史，不判 | — |

## 改进规则

1. 标题加入预算、周期或前后对比中的一项 → 本层可修
   → 回归钩子：下条只改一个主要变量，比较账号自身的点击与来源数据；无变化只记为本轮未支持标题假设。
2. 首图改为前后对比构图 → 本层可修
   → 回归钩子：比较同类内容的点击表现；无变化只削弱支持，不凭一条作废。
3. 若完整图序确认对比图未前置，再把最强对比放入前 3 图 → 文章层
   → 回归钩子：若后台提供翻页或完读数据，比较账号自身历史；没有该字段就保持未知。
4. 若完整正文确认没有材料与预算信息，再补一张清单 → 文章层
   → 回归钩子：比较同类内容的收藏表现，不套用行业基准。
5. 标签加入与内容真实对应的具体场景词 → 本层可修
   → 回归钩子：后台若提供搜索来源再比较；未提供就不归因。

**边界重申**：以上是内容工艺判断与 D 级假设，不是「没爆的原因」。要得到 B 级结论，请提供真实后台数据。

## 拒诊分支

**用户**：别讲假设了，你就说我是不是被限流了？

**Agent**：没有数据和平台通知，我不会给出这个结论。若后台有平台通知或分发限制提示，只能按通知明示的动作、范围和期限处理；没有通知既不能证明「被暗中限流」，也不能证明「绝未限流」。

所以要么补数据走完整归因，要么接受上面的质检。在此之前不输出「为什么没爆」的结论，也不给这次对话打诊断分；gate refusal 本身就是完整输出。
