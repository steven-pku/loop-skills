# Current Eval Assertions — 2026-09-20

This dated file corrects historical golden expectations without rewriting old case or run evidence. It is the current v0.3.0 behavior contract.

## Data Gate

- Explicitly synthetic or fictional numbers may demonstrate arithmetic only. They are not real dashboard data, must retain the user's stated source, and cannot produce a genuine Data Gate pass, B-grade performance attribution, or a Pass scorecard.
- `[附截图]`, a filename, an inaccessible attachment, or an unreadable/cropped screenshot is a placeholder, not data.
- Numbers explicitly transcribed from a dashboard may support B-grade observations, but their verification status is `用户转录，未独立核验`. Remembered estimates do not unlock attribution and are not C-grade evidence.

## Evidence Categories

- A requires that the current primary text was actually read and directly supports the exact claim. A URL, title, search snippet, or external-contribution page is insufficient.
- B means usable user data directly supports an observation; it does not mean the data was independently verified.
- C requires convergence across multiple independent practitioner sources. A single media paraphrase or external contribution is a D-grade unverified lead.
- The widely circulated CES formula remains an unverified claim, not an official formula.

## Arithmetic And Comparability

- `90 / 8000 = 1.125%`, not 1.5%.
- Metric definitions, observation windows, and distribution stages must be comparable before counts or ratios are compared. `7 days vs 2 hours` remains incomparable after conversion to percentages; report each side's arithmetic only and do not infer content quality.
- In a small sample, describe the current values before interpretation. Do not call a category better, worse, successful, or failed until windows and definitions are comparable.

## Routing

- Spoken-video hook, pacing, and narrative changes route to `脚本层`.
- Image/text body, paragraph order, list content, and image-sequence changes route to `文章层`.
- Title, cover or first image, tags, timing, and collection assignment route to `本层可修`.

## Regression Hooks

- One unchanged comparable next post means only `本轮未获支持`; it does not by itself falsify a content hypothesis.
- Prefer a queued repeated test and record whether support strengthens or weakens.

## Evaluation Standard

- Do not require an anchor-pair score gap of 25 points on a 25-point dimension.
- Judge the decisive behavior: Gate integrity, evidence category plus verification status, metric/window comparability, routing, regression-hook quality, fatal issues, and the rubric verdict band.
- Historical case text and historical run receipts remain frozen evidence. Any conflicting old expectation is `superseded`, not a current golden assertion.
