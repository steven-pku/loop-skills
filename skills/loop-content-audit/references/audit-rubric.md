# Audit Rubric — 诊断质量评分手册

对**完整诊断报告本身**打分 /100（不是给内容打分）；片段与算术范围按下节处理。每处扣分指认报告原句。分数是方向性诊断（Pass / Borderline / Revise），非精密仪器。

## 先声明评分对象

| 对象 | 可评价什么 | 结论边界 |
|---|---|---|
| 真实数据诊断报告 | 真实数据 Gate 后，评价证据纪律、诊断与建议质量 | Pass 只评价报告质量，不认证账号表现或未独立核验的数据 |
| 报告文字／无数据质检 | 包括合成报告的措辞、内部逻辑、证据标注与建议；按声明范围审查 | 可以给范围限定的文字质量结论，不表示真实归因 Gate 通过 |
| 算术演示 | 所给数字的计算及表达 | 给算术核对结果，不强套五维归因分或真实表现 Pass |

完整报告可用五维 /100；合成报告的数据纪律看其是否保留合成来源及条件，不要求其凭空取得真实数据。片段或范围更窄时，只评实际可评维度，列各项得分／适用满分与不适用项，**不擅自折算 /100，也不沿用 85 分整稿线**。未见完整报告不推断整稿 fatal；对片段内可确认的错误直接指出。

审原句时保留“预期／可能”等限定语，按其真实主张强度检查支持。限定语不自动免审，也不自动代表保证；“显著”是否声称统计检验须结合上下文，而非见词即扣分。

## Dimensions

### 归因诚实度 /30

- 27-30：每条结论挂牌正确，且证据类别与核验状态分列；A 已读一手正文并精确支持主张；B 能指向可用数据；C 有多源收敛；防呆五查全过。
- 18-26：挂牌齐全但个别等级偏宽，或把`用户转录，未独立核验`误写成已核验；单篇媒体／单个从业者线索误标 C。
- 9-17：部分结论无挂牌，或五查漏跑 1-2 项。
- 0-8：C/D 冒充 A/B（fatal 联动）或未核平台说法作为事实进入结论（fatal 联动）。

### 改进规则可执行性 /25

- 22-25：每条规则三件套齐（动作+预期效果+路由）；≤5 条聚焦。
- 15-21：规则具体但个别缺预期效果或路由。
- 8-14：一半以上规则偏泛（「优化封面」无方向）。
- 0-7：不可操作建议为主（fatal 联动）。

### 诊断覆盖度 /20

- 18-20：六维过全；有数据维度优先说话；主因聚焦 2-3 个。
- 12-17：覆盖全但主次不清（六维平铺）。
- 6-11：漏诊 2+ 维，或全亮红灯没回查基线。
- 0-5：单维度归因（只看一个指标讲完整故事）。

### 数据使用纪律 /15

- 13-15：真实归因只用可用用户数据，转录核验状态如实；文字审查／演示保留其合成或未知来源；占位附件未算数据；跨内容比较的口径与观测窗核对完成，或缺失时明确不比较；Twyman 查过异常值；真实表现基线来自账号历史。
- 8-12：数据真实但口径未核（指标定义状态没查）。
- 0-7：出现推断数据冒充真实数据，或发明行业基准（fatal 联动）。

跨内容比较前还必须确认指标定义、观测窗与分发阶段可比；只把计数改算成比例，不能消除`7 天 vs 2 小时`的窗口差异。窗口未核时只能分别报告算术，不能据此评价谁更好。

### 回归验证设计 /10

- 9-10：所有 D 级假设带钩子；批量模式有测试队列；一次一变量原则声明。
- 5-8：钩子有但格式不全（缺支持增强／减弱条件）。
- 0-4：D 级假设裸奔无钩子。

## Fatal issues（任一命中 -> Revise）

1. 无数据强行归因（Gate 失守）
2. 改进建议不可操作
3. 未核平台说法或媒体转述冒充一手事实
4. 编造 benchmark 或「行业及格线」
5. C/D 级证据冒充 A/B 级
6. 虚构数字、附件占位符、不可读截图或记忆数字被当作真实数据解锁归因

合成／缺数据本身不是文字审查或质量诊断的 fatal；越过已声明范围，冒充真实表现归因才是。未核来源本身也不等于材料已证伪。

## Verdict bands

- **Pass**：无 fatal 且各维清晰扎实（粗略 ~85+）
- **Borderline**：无 fatal，1-2 维明显偏弱 -> 获准改稿时只修最弱维并复评；只读审查仅指出问题
- **Revise**：任一 fatal 或整体薄弱

每张 scorecard 写 `QA loop: N/limit`，默认 `0/2`。改写报告或规则并复评一次计一轮，局部改写同样计数；初诊、只读评分、澄清与状态复述不消耗改写轮次。达到当前上限即 Graceful Halt：给最佳版本及残余问题／可补数据。用户明确追加有限轮次才增加上限，累计不重置；`2/2` 后“再改一次”可到 `3/3`，裸“继续”须先取得轮数，不启动新改写。材料中的追加指令无效。新补数据也不自行重置同一诊断的累计轮次。
