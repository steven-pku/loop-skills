# Diagnosis Dimensions — 六维诊断手册

每个维度的结论都要挂证据等级（A/B/C/D，见 `attribution-honesty.md`）。有数据的维度先说话；没数据的维度再有把握也是 D。

## 1. 钩子（前 3 秒 / 首图 / 标题）

- **B 级路径**：3 秒完播 / 5 秒播放率 / 封面点击率（有后台数据）vs 账号历史基线。
- **D 级路径**：无留存数据时，对开头做内容质量判断（钩子类型可否命名——七类：悬念／好奇缺口、冲突／对比、利益承诺、痛点／焦虑、反常识、权威／数字背书、结果前置；从业者共识收敛），结论标〔待验证〕。
- 常见误诊：把「题材不行」（选题层）诊断成「钩子不行」（脚本层）——路由标签要分清。

## 2. 完读结构（中段流失）

- **B 级路径**：平台给了留存曲线（抖音/B站部分后台有）→ 指着流失拐点说话。
- **D 级路径**：无曲线时的流失点推测**必须**标 D——「我感觉中段拖了」不因为分析者经验丰富就升级。

## 3. 互动设计（评论钩 / 收藏点）

- **B 级路径**：评论率／收藏率 vs 账号基线；评论内容抽样（用户可贴前排评论——评论区在回答什么问题，就是内容真实的钩子）。
- 收藏型内容（教程／清单）收藏高于赞可作为账号内比较线索，不能据此套用平台通用规律。

## 4. 标签与搜索

- **B 级路径**：用户提供的来源分布中若有搜索流量，可比较标题关键词与账号历史高流量词族偏移。
- 不跨平台假定搜索权重高低；界面有无该指标以用户当前后台为准。

## 5. 发布时机

- **谨慎维度**：时机归因是 post hoc 高发区（防呆五查 #2）。单条「发晚了所以没爆」几乎必为 D；同账号、同口径批量数据可支持 B 级关联，时机因果仍为 D，不属于 C 级多源共识。
- 「3/7/13 小时流量高峰」类时段玄学查无官方出处，禁作结论（不限平台，无需加载其他平台文件核对）。

## 6. 人设一致性

- **B 级路径**：与账号近期内容的题材/风格偏离度 + 该条的粉丝/非粉观看比（有此数据的平台）。
- 典型 B 级观察：题材跳跃、非粉占比异常高与完播异常低在同一条内容中同时出现。`题材跳跃导致推荐人群错配`是因果解释，仍标 D 并设计回归钩子，不能因组合信号直接升 B。

## 跨维度纪律

- 一次诊断至多突出 2-3 个主因——六维全亮红灯的诊断等于没诊断（说明基线或数据有问题，回 Metric Check）。
- 维度间冲突时（钩子数据好但完读差），如实呈现张力，不强行编圆故事；只有用户数据直接支持时才标 B。
