# Loop Skills · 让每一次修改都有依据

![Loop Skills — Draft. Review. Improve.](assets/og-card.jpg)

[English](README.en.md) · [如何选择](docs/choose-a-skill.md) · [场景示例](docs/scenarios.md) · [安装](docs/installation.md) · [验证与限制](docs/validation.md)

面向内容创作、职场沟通、决策与学术准备的一组独立 Agent Skills。先把目标和材料说清楚，再形成草稿、按标准检查、有限修订，最后交付结果与尚未解决的问题。

**选择一款即可开始。** 你不需要安装全套，也不需要接受统一的自动工作流。每款保留自己的输入要求、资源和停止条件。

> 本仓集中提供十五款产品的源码与独立下载。九款保留已有运行版本，六款为实验性产品。本次是文档与分发整理，新分发尚未完成双宿主行为验证，不代表新的功能验收。

## 先试一个小问题

如果你有一段文字，先试 Article Writer 的 `QA Only`，不用从完整长文开始：

```text
使用 loop-article-writer 的 QA Only。
请检查：所有人都应该每天五点起床，因为成功人士都这样做。
先指出推理与证据缺口，不直接替我补充研究或数据。
```

这是教学请求，不是已经执行的测试。检查输出是否区分“给定观点”“待核事实”和“推理问题”，并保留缺失依据。其他场景见[六组示例](docs/scenarios.md)。

## Loop 如何工作

![目标、草稿、评审、有限修订与交付](assets/loop-cycle.svg)

“Loop”是一种有终点的修订方式。产品先确认任务是否适用，再使用自己的检查标准；达到本轮修订上限、缺少必要材料或遇到超出范围的请求时，应停下并解释原因。评分帮助定位问题，不能替代事实核验，也不能授权发布或操作外部账号。

## 不同产品怎样配合

选题可以为文章或脚本提供材料；简历中的真实经历账本可以帮助面试准备。交接由你发起，下一款仍要重新确认范围与依据，不自动继承上一款的评分、真实性判断或行动权限。

## 安装与升级

下载一款完整目录，并在目标宿主的新会话中显式调用。目录复制、摘要与恢复检查已完成；模型实际加载与行为仍待验证，详见[安装说明](docs/installation.md)。保留已有修改；下载、源码与问题反馈集中在本仓。

## 实验室

论文与实习产品帮助组织材料、建立证据与发现问题，不代替导师、伦理审查、招聘判断或学校政策。已知问题列在各产品的 `REVIEW.md`。不要把可阅读源码理解为通过了真实使用验收。
