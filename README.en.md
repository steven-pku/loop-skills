This is an overview, not a line-by-line translation. The [Chinese README](README.md) is the primary guide.

## What it is

A directory of independently released writing skills. Each uses explicit review criteria and bounded revision to help identify and improve weak drafts.

## Available releases

- [Article Writer v0.3.0](https://github.com/steven-pku/loop-article-writer/releases/tag/v0.3.0): Chinese opinion articles, stance checks, structural review and fact discipline.
- [Report Writer v0.3.1](https://github.com/steven-pku/loop-report-writer/releases/tag/v0.3.1): weekly reports and promotion materials grounded in a user-supplied achievement ledger.

## Public review candidates

A separate [review directory lists 13 candidates](REVIEW-CANDIDATES.md), with pinned commits, review scope, REVIEW links, and a short read-only review prompt. All remain **HOLD** and are outside the available-releases list. Public source does not mean a formal release, verified behavior, or an installation recommendation.

## Start

Open the selected release and follow its README for supported, project-scoped installation and a minimal first-use example. This directory itself is not an installable skill and has no `SKILL.md`.

## Limits

Instructions depend on the host model following them. Scores are review aids, not calibrated measurements or guarantees. Each release documents its actual tests and remaining limitations; installation and model behavior are separate checks. Review outputs and redact private information before sharing them with a model host or a public issue.

The available-releases list grows only after an actual public release. Development candidates are listed separately for review and are not recommended for installation. The [Loop Pattern](LOOP-PATTERN.md) describes the common approach.
