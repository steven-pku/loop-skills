# 修改依赖与变更传播

## 默认依赖

```text
研究问题
  -> 理论与概念
  -> 变量／访谈主题
  -> 方法与数据
  -> 结果解释
  -> 章节结构
  -> 局部措辞与格式
```

这不是所有论文的固定结构。它是默认检查顺序，必须按用户材料校正。

## 建边规则

当任务 B 的正确做法取决于任务 A 的结果时，建立 `A -> B`。

常见依赖：

- 研究对象变化 -> 样本、文献范围、结论适用范围；
- 研究问题变化 -> 理论、变量、方法、章节结构；
- 概念定义变化 -> 测量、编码、结果解释；
- 数据来源变化 -> 方法、限制、结论强度；
- 方法变化 -> 分析、结果、讨论和摘要；
- 结论降级 -> 标题、摘要、讨论和建议。

## 执行顺序

1. 先解决有最多下游影响的 P0；
2. 再解决证据和论证 P1；
3. 最后做措辞与格式 P2。

并行任务必须不存在直接依赖，并且不会修改同一论文位置。

## 变更传播检查

每次上游任务关闭前，列出：

- 受影响下游任务；
- 需要重做的已完成项；
- 可能失效的证据；
- 需要导师确认的范围变化。

## 返工判定

以下情况不是回归失败，而是必要返工：

- 上游问题在后续轮次才被确认；
- 导师给出新反馈；
- 学校规则更新；
- 新证据推翻原假设。

以下情况属于执行失败：

- 已知上游变化却未检查下游；
- 为保持“已完成”状态而忽略冲突；
- 只更新摘要，不更新正文或方法；
- 依赖项未关闭却把下游标为 `Closed`。
