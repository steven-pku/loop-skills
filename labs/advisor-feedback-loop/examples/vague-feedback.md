# 示例｜模糊反馈

## 输入

导师原话：

> 理论部分太散，研究问题也不够集中，方法再想想。

论文摘要：研究大学生短视频使用、平台信任、学习投入、社交焦虑与就业信心之间的关系，计划发放横截面问卷。

## 原子化

| ID | 原话 | 明确要求 | 可能含义 | 状态 |
|---|---|---|---|---|
| F01 | 理论部分太散 | 理论部分需要收敛 | 理论数量过多，或理论与问题未形成关系 | Need Advisor Confirmation |
| F02 | 研究问题也不够集中 | 研究问题需要缩小 | 变量过多或研究对象／机制不清 | Open |
| F03 | 方法再想想 | 方法需重新审视 | 横截面问卷可能不能支持当前因果表达 | Need Advisor Confirmation |

## 依赖

```text
F02 -> F01 -> F03 -> 结果解释与措辞
```

## 导师确认问题

1. 您说“研究问题不够集中”，更希望我减少变量，还是保留变量但收窄研究对象与机制？
2. “方法再想想”主要指问卷设计本身，还是当前问题使用了超过横截面问卷支持范围的因果表述？

## 判决

先处理研究问题，暂缓大规模理论补写和语言润色。不得把两种可能解释写成导师已确定的修改方向。
