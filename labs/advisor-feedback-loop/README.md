## 开始前准备

导师反馈原文、论文位置与已完成修改证据。缺失信息可以标记为未知；不要用看似合理的数字、来源或经历填补空缺。请先去除姓名、联系方式和无权分享的材料。

## 你会得到什么

意见到动作的映射、修改计划与关闭检查。结果需要由你核对实际材料，再决定是否采用。评分或状态标签只解释本次检查，不代表事实已核实或允许自动采取下一项行动。

## 试一次

以下是合成教学请求，展示如何提供边界；不是本次实测输出。

```text
使用 advisor-feedback-loop。
请把导师反馈逐条对应到修改动作。模糊意见先列确认问题，不能自行宣布问题已经关闭。
```

阅读结果时，检查它有没有分开已知事实、推断和缺失材料；有没有保留原输入的限定条件；有没有在需要你补充或确认时停下。
