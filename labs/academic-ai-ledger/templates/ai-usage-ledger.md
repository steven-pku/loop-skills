## 追加规则

- 新事件追加到表尾，Event ID 不复用；
- 历史行不覆盖，更正走 `Correction Event` 并回指原 Event；
- `updated` 覆盖为当前日期；
- 每次追加后检查 Event ID 唯一、披露引用的 Event 存在、历史仍可追溯。

## 记录纪律

- 只记录用户能确认的事实；
- 时间记不清就记区间，不编造具体日期；
- 不补造提示词、对话或截图；
- 不删除已披露过的事件。
