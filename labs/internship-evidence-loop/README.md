# 实习成果整理 · internship-evidence-loop

[返回系列目录](https://github.com/steven-pku/loop-skills) · [运行指令](SKILL.md) · [验证范围](REVIEW.md)

行动、产物、结果和证据的对应账本。适合你已经有本人任务、产物、反馈及允许留存的脱敏证据，希望把下一步做得更明确的情境。

**状态：实验性，尚未正式发行。** 本产品仍存在已知问题，尚未完成真实使用验收。只用于合成或脱敏材料的研究与评估。

## 开始前准备

本人任务、产物、反馈及允许留存的脱敏证据。缺失信息可以标记为未知；不要用看似合理的数字、来源或经历填补空缺。请先去除姓名、联系方式和无权分享的材料。

## 你会得到什么

行动、产物、结果和证据的对应账本。结果需要由你核对实际材料，再决定是否采用。评分或状态标签只解释本次检查，不代表事实已核实或允许自动采取下一项行动。

## 试一次

以下是合成教学请求，展示如何提供边界；不是本次实测输出。

```text
使用 internship-evidence-loop。
我参与了一个团队项目。请分别记录团队成果与我的具体工作，对无法证明的结果保留未知。
```

阅读结果时，检查它有没有分开已知事实、推断和缺失材料；有没有保留原输入的限定条件；有没有在需要你补充或确认时停下。

## 适用边界

不夸大个人贡献，不带离保密原始资料。具体规则以本目录的 `SKILL.md` 与随附资源为准。不要仅复制一个入口文件；运行所需资源要随整个产品目录一起安装。
