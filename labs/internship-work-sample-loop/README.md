## 开始前准备

运营岗位要求、已有能力和可用公开材料。缺失信息可以标记为未知；不要用看似合理的数字、来源或经历填补空缺。请先去除姓名、联系方式和无权分享的材料。

## 你会得到什么

个人项目计划、作品证据和展示说明。结果需要由你核对实际材料，再决定是否采用。评分或状态标签只解释本次检查，不代表事实已核实或允许自动采取下一项行动。
