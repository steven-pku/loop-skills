# 伦理、授权与隐私红旗

## 先看研究对象

| 对象 | 处理 |
|---|---|
| 成年一般人群 | 在适用范围内，走常规知情同意 |
| 本人所在单位的同事或下属 | 存在权力关系，需说明自愿性保障 |
| 未成年人 | 超范围，需监护人同意与伦理审查 |
| 患者、就诊人群 | 超范围，转专业人工与伦理审查 |
| 受灾、受创、受虐群体 | 超范围，转伦理审查 |
| 涉及违法或违规行为的当事人 | 超范围，涉及举报风险与法律风险 |

对象超范围时，伦理闸门直接判 Fatal，不进入缩题，除非用户改换研究对象。

## 知情同意

检查四项：告知研究目的、告知数据用途与保存期限、告知可随时退出、取得可留痕的同意记录。

四项缺任一项，伦理闸门不得高于 3 分。全部缺失且用户没有补救计划，判 Fatal。

访谈录音必须单独取得同意，不得默认口头同意涵盖录音与转写。

## 数据授权

| 数据来源 | 必须确认 |
|---|---|
| 学校或机构订阅数据库 | 使用范围是否包含学位论文、是否允许导出 |
| 企业提供的内部数据 | 是否有书面同意、是否需脱敏、是否限制发表 |
| 平台公开页面 | 抓取是否违反使用条款、频率与范围限制 |
| 政府公开数据 | 引用与再发布要求 |
| 他人已收集的数据 | 原始知情同意是否覆盖二次使用 |

无法确认时写 `Unknown`，并把「取得书面确认」列为补证动作。不得假设「公开就等于可用」。

## 隐私与去标识

- 不索取、不接收可识别个人信息表；
- 姓名、学号、工号、手机号、身份证号、精确住址一律不进入分析材料；
- 小样本中职务加单位即可定位到人，需要合并类别或改用编号；
- 引用访谈原话时删除可定位细节；
- 敏感材料提醒用户先脱敏再分享，只提醒一次。

## 伦理审批

需要审批时，把审批周期算进倒排计划。审批周期未知时按 `Unknown` 处理，并提示这可能吃掉数月时间。

用户表示「学校不要求审批」时，记录为 `P2` 级信息，写明依据来源，不作为已确认事实。

## Fatal 清单

- 研究对象属于本流程范围外的高风险人群；
- 需要涉密、未公开或无权分享的数据；
- 无法取得知情同意且没有合规替代设计；
- 数据授权确定拿不到；
- 敏感人群或未公开个体名单，且授权状态未证实——按 Fatal 处理并判 `NO-GO`（写明「补证授权后可重评」），不得因「待核」只标 Unknown 或停在候选 Fatal；
- 伦理审批确定无法在截止时间前完成；
- 用户要求伪造同意记录、授权文件或伦理审批材料。

Fatal 一旦成立，无论总分多高都不得判 `GO`。

## 不做的事

- 不代写知情同意书的法律效力承诺；
- 不判断某项研究是否需要伦理审查的最终结论，只给出需向委员会确认的问题；
- 不评估法律风险，只标出需要专业意见的位置。
