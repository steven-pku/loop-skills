# 示例｜修改后全链复核

## 背景

第一轮判决 `暂停发放`，三条 Fatal：

- F1：跳转逻辑把有实习经历的受访者跳过了核心变量题块；
- F2：问卷声称匿名，但收集了学号和手机号；
- F3：研究问题写作「实习强度导致就业信心提升」，设计是横截面自陈问卷。

用户提交第二轮修订版。

## 用户的修订

> 1. 跳转改了：Q05 选「有实习经历」跳到 Q06，选「无」跳到 Q20。
> 2. 学号删了，手机号挪到问卷最后做抽奖用，说明里写了「本问卷匿名」。
> 3. 研究问题改成「实习强度与就业信心的关系」，摘要没动。
> 4. 顺便加了 3 道实习满意度题。

## 全链复核

复核不只看被改动的题，要沿整条链重走。

### 1. 跳转

| 检查项 | 结果 |
|---|---|
| 触发条件与目标题号 | Q05=有 → Q06；Q05=无 → Q20 |
| 核心变量题块位置 | Q06-Q19 |
| 无实习经历者路径 | 跳过 Q06-Q19，直达 Q20 |
| 是否误排除核心样本 | 否。目标总体本就限定为有实习经历的学生 |
| 孤儿题 | 无 |
| 必答冲突 | Q08 被跳过但仍设必答 |

F1 状态：`Fixed`，跳转本身已正确。新发现 Major：Q08 必答冲突会导致无实习经历者无法提交。

### 2. 隐私与知情

| 检查项 | 结果 |
|---|---|
| 学号 | 已删除 |
| 手机号 | 仍收集，位置改到末尾 |
| 说明表述 | 「本问卷匿名」 |

F2 状态：`Open`。收集手机号即可对应到个人，声称匿名不成立，仍命中 Fatal 清单第 3 条的知情说明不实。

修复二选一：

- 删掉手机号，抽奖改为独立链接，与答卷不关联；
- 保留手机号，说明改为「本问卷保密收集」，补充存储位置、保留期、删除时间，并声明不填手机号不影响提交。

### 3. 推断边界传播

研究问题已从因果改为关系，但下游未跟着改：

| 位置 | 当前表述 | 需要改 |
|---|---|---|
| 研究问题 | 实习强度与就业信心的关系 | 已改 |
| 假设 H1 | 实习强度正向影响就业信心 | 是 |
| 摘要 | 实习经历提升了大学生就业信心 | 是 |
| Q22 题干 | 您认为实习在多大程度上提升了您的就业信心 | 是。题干本身预设了因果 |

F3 状态：`Partially Fixed`。上游已改，下游三处仍是因果表述，Fatal 未关闭。这是典型的只改上游不传播。

### 4. 新增题项

用户新加的 3 道实习满意度题必须走完整审计，不能因为是新加的就跳过：

- 「满意度」在覆盖矩阵中无对应研究问题 → 无归属题项，建议删除或补充研究问题；
- 3 题采用 7 点量表，问卷内其他量表为 5 点 → 量表点数混用，Major；
- 问卷总时长从 9 分钟增至 11 分钟，仍在可接受范围。

## 判决

第二轮复核：`暂停发放`。

理由：F2 与 F3 未关闭。按循环上限，本 Skill 最多 2 轮；第二轮仍有 Fatal，判定暂不建议发放，交由用户完成修复后另行发起复核。

## 输出

**发放判决**：`暂停发放`。

**Facts**：跳转已修正；学号已删除；手机号仍收集；研究问题已改为关系表述；新增 3 题 7 点量表。

**Assumptions**：手机号仅用于抽奖。用户未说明存储与删除安排，此为推断。

**Unknowns**：学校是否要求伦理审查；抽奖信息的存储位置。

**Fatal**：匿名声明与手机号收集冲突；因果表述在假设、摘要和 Q22 中残留。

**Major**：Q08 必答冲突；量表点数混用；新增题项无研究问题归属。

**下一步**：处理手机号与知情说明 → 清理三处因果表述 → 解除 Q08 必答 → 统一量表点数或说明不合成。

**停止原因**：达到最大轮次（2/2）且仍有 Fatal。

## 禁止做法

- 因为跳转已修好就把整体判为「修改后可发」；
- 只复核用户点名改过的部分，不查新增题项；
- 因为用户说「顺便加了 3 道题」就默认这 3 题没问题；
- 在第二轮仍有 Fatal 时开第三轮继续改。
