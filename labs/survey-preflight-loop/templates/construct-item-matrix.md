# 变量—题项覆盖矩阵

## 研究链

```text
研究问题 → 概念 → 变量 → 题项 → 编码 → 分析
```

## 覆盖矩阵

| 研究问题 | 概念 | 变量名 | 角色 | 题项 | 题项数 | 测量层次 | 用于哪步分析 | 覆盖状态 |
|---|---|---|---|---|---:|---|---|---|
| RQ1 |  |  | 自变量 | Q__ |  |  |  | 已覆盖 |
| RQ1 |  |  | 因变量 | Q__ |  |  |  | 未覆盖 |

角色取值：自变量、因变量、中介变量、调节变量、控制变量、筛选变量、描述变量。

覆盖状态取值：

- `已覆盖`：题项数充足且题干与变量定义一致；
- `部分覆盖`：有题项但不足以支持计划分析；
- `未覆盖`：无题项，核心变量未覆盖即 Fatal；
- `待确认`：变量定义或分析用途未知。

## 无归属题项
