# 知情、隐私与数据最小化

## 一、数据最小化

对每个收集项问三个问题：

1. 这个变量在分析计划里用来做什么？
2. 不收它，研究问题还能不能回答？
3. 有没有敏感度更低的替代形式？

三问都答不上来的收集项直接删。

### 敏感度分级

| 级别 | 内容 | 默认处理 |
|---|---|---|
| 高 | 姓名、手机号、身份证号、学号、工号、住址、人脸、精确定位 | 默认不收；确需联系时单独授权并与答卷分离存储 |
| 中 | 精确出生日期、具体单位或班级、精确收入、健康状况、宗教、政治态度 | 改区间或改类别；必须给「不愿回答」 |
| 低 | 年龄段、性别、学历段、地区、行业 | 按分析需要收 |

收集高敏感信息但缺必要性说明或知情说明，判 Fatal。

### 抽奖与联系方式

需要抽奖或回访时：

- 联系方式单独放在问卷末尾的独立环节；
- 明确说明联系方式与答卷分开存储、只用于该用途、何时删除；
- 不填联系方式不影响提交。

## 二、知情说明必备要素

知情说明缺任一必备要素判 Major；同时缺三项以上或涉及敏感信息时判 Fatal。

| 要素 | 内容 |
|---|---|
| 研究目的 | 一句话说明研究要回答什么，用受访者能懂的话 |
| 主办方 | 学校、院系、研究者身份与联系方式 |
| 内容与时长 | 问卷主题与预计完成时间 |
| 自愿参与 | 参与自愿，不参与无不利后果 |
| 退出机制 | 可随时关闭页面退出，已填部分如何处理 |
| 数据用途 | 仅用于学术研究，是否会公开、以何种形式公开 |
| 匿名或保密 | 匿名收集，还是收集可识别信息后做保密处理，两者不可混称 |
| 存储与删除 | 存放在哪里、保存多久、何时删除 |
| 风险与收益 | 一般问卷可写「无可预见风险」；涉及敏感话题必须如实说明 |
| 同意确认 | 明确的开始作答即视为同意，或独立的同意勾选项 |

## 三、匿名与保密的区别

- **匿名**：研究者本人也无法把答卷对应到个人。收了手机号、学号或精确单位就不是匿名。
- **保密**：能对应到个人，但承诺不对外披露。

问卷声称匿名却收集可识别信息，判 Fatal。修复方式二选一：删掉可识别项，或把说明改为保密并补充存储与删除安排。

## 四、伦理审查

- 学校或学院要求伦理审查时，审查通过是发放前提，不是可选项；
- 涉及敏感话题、特殊人群或报酬激励时，主动提示用户确认审查要求；
- 本流程不替代伦理审查，也不判断审查能否通过；
- 审查要求未知时，写入未验证项，不假设「一般问卷不用审」。

## 五、平台与存储

- 提醒用户确认问卷平台的数据存储地、导出权限与保留期限；
- 不要求用户上传含个人信息的原始导出文件；
- 用户粘贴内容中出现受访者姓名、电话或身份证号时，立即提示脱敏，并且不在输出中复述这些信息。

## 六、退出与部分作答

- 明确部分作答数据是否保留；
- 必答题设置要克制，全问卷必答会把退出变成放弃，抬高中途流失；
- 敏感题一律不设必答。

## 七、未成年人

受访者可能包含未成年人时：

- 需要监护人知情同意，且题目与说明要适配理解水平；
- 本流程判 `OUT_OF_SCOPE`，转伦理审查与专业人工；
- 只提供需要向学校确认的问题清单，不给发放判决。

## 严重度对应

| 问题 | 默认严重度 |
|---|---|
| 收集高敏感信息且无必要性或知情说明 | Fatal |
| 声称匿名但收集可识别信息 | Fatal |
| 无知情说明 | Fatal |
| 知情说明缺单个必备要素 | Major |
| 无退出机制 | Major |
| 敏感题设为必答 | Major |
| 存储与删除安排未写 | Major |
| 联系方式与答卷未分离 | Major |
| 收集无分析用途的人口学变量 | Minor |
