# 编码与分析准备度

发放前就要能回答：数据回来以后，每一题变成什么变量、怎么算、支持什么结论。

## 一、变量登记

每题至少登记：

- 题号；
- 变量名（英文短名，跨软件通用）；
- 目标构念；
- 测量层次（名义／有序／等距／比率）；
- 取值与编码；
- 是否反向计分；
- 缺失值编码；
- 参与哪一步分析。

登记不全的题项进入待补清单，不能算作分析就绪。

## 二、编码规则

- 单选题按选项顺序编码，编码值与量表方向一致；
- 多选题展开为每个选项一个 0/1 变量，变量名带统一前缀；
- 开放题给出编码类目草案、编码者与一致性检查方式；
- 排序题按位次编码，并说明未排序项如何处理；
- 反向题在编码方案中单列清单，写明反向公式，如 6 减原值适用于 5 点量表。

反向计分清单缺失、或反向公式与量表点数不匹配，判 Major；导致核心变量计分错误时升 Fatal。

## 三、缺失值

- 系统缺失（跳转跳过）与用户缺失（不愿回答、不知道）必须用不同编码；
- 「不适用」不是缺失，要单列编码；
- 事先写明缺失处理策略：整行剔除、单题剔除还是插补，以及触发条件；
- 说明允许的最大缺失比例，超过即剔除该份问卷。

## 四、量表合成

- 只有同一构念、同一点数、方向已统一的题项才能合成；
- 写明合成方式（均值或求和）以及缺失题项时的处理；
- 计划报告内部一致性系数时，说明它衡量的是一致性，不是效度；
- 合成前必须完成反向计分。

## 五、分析计划对齐

逐条核对：每个研究问题或假设 → 用到哪些变量 → 用什么分析 → 需要什么数据条件。

| 分析 | 数据条件 | 常见缺口 |
|---|---|---|
| 频数与描述 | 变量有明确取值 | 开放题无编码类目 |
| 组间比较 | 分组变量各组样本充足 | 分组变量收成了开放题 |
| 相关分析 | 两变量均为连续或有序 | 核心变量只有单题名义测量 |
| 回归 | 因变量连续、自变量齐备、控制变量已收 | 控制变量没出题 |
| 调节或中介 | 三个变量都有独立测量 | 调节变量缺题项 |

分析计划需要的变量在问卷里没有对应题项，判 Fatal。

## 六、推断边界

横截面自陈问卷不能直接支持因果结论。以下表述在题目、假设、摘要中都要改：

| 禁止表述 | 可用表述 |
|---|---|
| A 导致 B | A 与 B 存在关联 |
| A 提升了 B | A 水平较高的受访者报告的 B 水平也较高 |
| A 的影响机制是 C | 数据可检验 C 是否在 A 与 B 关联中起统计中介作用 |
| 结论适用于全国大学生 | 结论适用于本次样本所覆盖的人群 |

用横截面自陈问卷得出强因果结论，判 Fatal。修复方式：降低表述强度、补充设计（追踪、实验、多来源数据），或在局限中明确写清。

自陈数据还有共同方法偏差风险。同一受访者同时报告自变量与因变量时，在局限中说明，并考虑分离测量时点或增加客观指标。

## 七、预测试的边界

预测试可以给出：可理解性、歧义、跳转错误、无法回答项、完成时长、题目冗余。

预测试不能给出：信度系数结论、效度证据、因子结构、可推广的总体估计。

把预测试结果说成信效度检验，判 Fatal。正式信效度检验需要独立、足量的正式样本与预先设定的分析方案，本流程只做发放前准备。

## 八、伪造阻断

以下请求一律拒绝并记 Fatal：

- 生成、模拟或补全问卷回收数据；
- 编造预测试参与人数、反馈或修订记录；
- 给出未经真实计算的信度或效度数值；
- 编造回收率、有效问卷数或剔除比例；
- 把已收集数据的题目倒改成更利于结论的版本。

替代路径：给出真实可执行的预测试计划、编码方案和分析准备清单，让用户拿真实数据自己跑。

## 严重度对应

| 问题 | 默认严重度 |
|---|---|
| 分析需要的变量无对应题项 | Fatal |
| 横截面自陈得出强因果结论 | Fatal |
| 预测试冒充信效度 | Fatal |
| 编造数据或结果 | Fatal |
| 反向计分清单缺失 | Major |
| 缺失值编码未区分 | Major |
| 合成规则未写 | Major |
| 开放题无编码计划 | Major |
| 共同方法偏差未说明 | Minor |
